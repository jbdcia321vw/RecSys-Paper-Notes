    🏛️ SIGIR 2023 推荐系统论文解读

    56 篇 SIGIR 2023 论文解读，覆盖 15 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🔥 高频主题： 多模态推荐 ×4 · 对比学习 ×4 · 端到端生成式 ×3 · 离线强化学习 ×2 · 课程学习 ×2

    🏷️ 标签筛选 仅显示 ≥2 篇论文的标签；默认 AND

    🤝 协同过滤与双塔召回 (6)

    A Personalized Dense Retrieval Framework for Unified Information AccessSIGIRCF2023

    提出统一信息访问双塔框架UIA，用功能编码+用户历史注意力个性化，在Lowe’s/ESCI全库排序显著超越任务专用与联合训练基线。

    A Transformer-Based Substitute Recommendation Model Incorporating Weakly Supervised Customer Behavior DataSIGIRCFDebias2023

    以商品标题对+XLMR交互匹配替代关系，PR对数回归与负采样去噪，11市场单模型A/B收入+19%。

    Blurring-Sharpening Process Models for Collaborative FilteringSIGIRCFGraph2023

    提出免训练 ODE 模糊-锐化范式直接处理交互矩阵，在三个基准全库排序 Recall/NDCG 超 43 个基线，NDCG 最高提升 3.74%。

    Continuous Input Embedding Size Search For Recommender SystemsSIGIRCFRL2023

    用 TD3 在连续动作空间为每个用户/物品搜索任意粒度 Embedding 尺寸，并以随机游走探索提升收敛，80–95% 稀疏率下 R@20 全面超越离散 RL 搜索。

    Curse of \"Low\" Dimensionality in Recommender SystemsSIGIRCFDebias2023

    论证点积模型低维嵌入是可表示排序数指数级塌缩的根源，实证其加剧流行度偏差、损害多样性与公平性，并给出上界 $n^{2d}$ 与锥体刻画。

    Disentangled Contrastive Collaborative FilteringSIGIRCFSSL2023

    以 K 个全局意图原型解缠用户/物品表征，并用解缠相似度驱动参数化图掩码做自适应对比增广，全库排序下 Recall@20 相对最优基线提升 2.8%–6.3%。

    🕸️ 图神经网络与知识图谱推荐 (4)

    Graph Collaborative Signals Denoising and Augmentation for RecommendationSIGIRGraphSSL2023

    预训练后双边 Top-K 重连二部图并补入用户-用户/物品-物品对称相关块，Amazon 全库排序 NDCG@20 相对提升 6.9%–13.4%。

    LogicRec: Recommendation with Users' Logical RequirementsSIGIRGraphMTL2023

    将用户逻辑需求形式化为 KG 结构化逻辑查询，用 LQE 联合推断缺失事实并以多任务多门专家共享 A_l/A_u 答案集，Amazon-book hit@20 相对提升约 22%。

    Sharpness-Aware Graph Collaborative FilteringSIGIRGraphCold2023

    用双层优化+隐函数超梯度把锐度感知训练引入GNN协同过滤，全库排序下LightGCN骨干Recall@20最高提升13.48%。

    Triple Structural Information Modelling for Accurate, Explainable and Interactive RecommendationSIGIRGraphSeq2023

    增量SVD低通滤波＋无参数注意力＋物品转移矩阵三源融合，全库排序 HR@10 最高相对提升 203.8%，并支持频率级可解释交互推荐。

    🔄 自监督对比学习与交互去噪 (6)

    A Directional Diffusion Graph Transformer for RecommendationSIGIRSSLGraph2023

    以各向异性方向高斯噪声替代等方向噪声做嵌入级扩散，并用条件线性 Transformer 反向去噪，全库排序 Recall@20 相对 SOTA 提升约 3–4%。

    Generative-Contrastive Graph Learning for RecommendationSIGIRSSLGraph2023

    以变分图重构采样替代数据增广生成对比视图，联合节点/簇级对比，在三个数据集 Full-Ranking 下 NDCG@20 较 LightGCN 提升 8.61%–28.17%。

    Graph Transformer for RecommendationSIGIRSSLGraph2023

    GFormer 用拓扑感知图 Transformer 参数化发现协同 rationale 子图，并以 rationale-aware 掩码自编码替代随机对比增广；全库排序下 Recall@20 较 SGL 提升 5.2%–7.7%。

    Improving Implicit Feedback-Based Recommendation through Multi-Behavior AlignmentSIGIRSSLCross2023

    将用户真实偏好设为隐变量，用 KL 散度对齐点击/购买两条行为链并交替去噪，三数据集 Recall@20 相对最优基线提升 0.5%–6.6%。

    Knowledge-refined Denoising Network for Robust RecommendationSIGIRSSLGraph2023

    KRDN 用伯努利掩码剪枝 KG 任务无关三元组，并以协同/知识信号分歧对比式剔除噪声交互；全库排序下 NDCG@20 较 SOTA 提升 4.6%–12.7%。

    Multi-behavior Self-supervised Learning for RecommendationSIGIRSSLGraph2023

    行为感知GNN+双层自判别对比+梯度混合矫正，Leave-One-Out全库排序下Recall@10平均提升约19%

    ⏱️ 序列与会话推荐 (9)

    Attention Mixtures for Time-Aware Sequential RecommendationSIGIRSeqCTR2023

    用高斯混合注意力量化物品与时间上下文两条注意力流的权重，并融合 Attentive FISM 长兴趣，1K 采样排序下 HR/NDCG@10 全面领先时序 Transformer。

    Ensemble Modeling with Contrastive Knowledge Distillation for Sequential RecommendationSIGIRSeqSSL2023

    用 N 个并行双向 Transformer 做序列编码器集成，并以 ICL/CCL 表征对比蒸馏 + logits 协同 KL 蒸馏打通网络间知识迁移；5-core + Leave-One-Out + 全库排序下 NDCG@10 相对提升 20.7%~33.5%。

    Frequency Enhanced Hybrid Attention Network for Sequential RecommendationSIGIRSeqSSL2023

    将用户行为序列迁移到频域，用频率斜坡采样改造自注意力并叠加自相关周期注意力，Leave-One-Out 全库排序下在四个基准上实现 3.6%–10.9% 的稳定提升。

    Graph Masked Autoencoder for Sequential RecommendationSIGIRSeqSSL2023

    MAERec 用以任务自适应路径掩码驱动的图掩码自编码器替代手工对比增广，在留一法全库排序下 HR@20 相对最强基线提升最高 11.5%

    LinRec: Linear Attention Mechanism for Long-term Sequential Recommender SystemsSIGIRSeq2023

    用 ELU + 行/列 L2 归一化替换 Softmax，令 QK^T V 可交换计算顺序，把长序列自注意力从 O(N²) 降到 O(N)，并在 ML-1M/Gowalla 全库排序上持平或超越 SASRec/BERT4Rec。

    Meta-optimized Contrastive Learning for Sequential RecommendationSIGIRSeqSSL2023

    用可学习模型增强器与元学习优化对比学习，在 LOO+Full-Ranking 下 HR/NDCG 相对最强基线提升 2.5–8.4%。

    MobileRec: A Large-Scale Dataset for Mobile Apps RecommendationSIGIRSeqCold2023

    构建 19.3M 条 Google Play 用户-App 时序交互（10,173 App / 48 类 / 0.7M 用户），提供 uid、时间戳与 App 元数据，并以 Leave-One-Out + Full-Ranking 协议给出 9 个序列推荐基线。

    Neighborhood-based Hard Negative Mining for Sequential RecommendationSIGIRSeqSSL2023

    在全局加权物品转移图上以 Jaccard 邻域重叠度构造难负采样分布，并用课程学习调度假阴性阈值；在三个 Amazon 数据集 Leave-One-Out + 1000 候选采样排序下，相对最强负采样基线 NDCG@20 稳定提升 1.0–2.0%。

    When Search Meets Recommendation: Learning Disentangled Search Representation for RecommendationSIGIRSeqSSL2023

    SESRec 用查询-物品对齐 + 三元组对比自监督把搜索/推荐行为解耦为相似与相异兴趣，在快手与 Amazon 上 NDCG@10 相对提升 7.05%/2.48%。

    ✨ 生成式推荐与离散语义 ID (1)

    Diffusion Recommender ModelSIGIRGenRecCF2023

    首次将扩散模型引入全物品交互生成式推荐，通过缩小噪声尺度并预测 x0 保留个性化信息，辅以物品聚类隐空间扩散与时间重加权，Full-Ranking 下 R@10 最高提升 10.67%。

    🧠 大语言模型推荐 (LLM4Rec) (1)

    Prompt Learning for News RecommendationSIGIRLLM4RecCold2023

    首次将新闻点击预测改写为完形填空式 MLM 任务，设计离散/连续/混合三类模板与多模板概率集成；MIND 上 1:4 采样排序评测，跨类型集成 AUC 69.64，较 BERT-NRMS 相对提升 1.5%–4.8%。

    🗣️ 对话推荐与智能体仿真 (2)

    Multi-view Hypergraph Contrastive Policy Learning for Conversational RecommendationSIGIRCRSGraph2023

    用三视图动态超图+分层超图编码+跨视图对比策略学习建模对话推荐中的多源用户偏好，Yelp 上 SR@15 提升 18.28%。

    Towards Explainable Conversational Recommender SystemsSIGIRCRSLLM4Rec2023

    提出 CRS 可解释性 10 维评估视角，构建含 2,058 条高质量解释的 E-ReDial 数据集，T5+知识接地生成 Explanations 时 F1 提升 21.8%、人工总体评分从 1.14 提升至 3.67。

    🧩 多模态推荐与内容理解 (4)

    Enhancing Dynamic Image Advertising with Vision-Language Pre-trainingSIGIRMMCTR2023

    用 20B 图文预训练 + 相关性蒸馏统一广告图检索与相关性重排，百度线上 CPM/CTR 提升 1.04%/1.865%。

    Mining Stable Preferences: Adaptive Modality Decorrelation for Multimedia RecommendationSIGIRMMDebias2023

    用 HSIC 度量模态相关度并做样本重加权，把多模态推荐从虚假偏好拉到稳定偏好，四骨干四数据集 IID 平均涨 3–22%、OOD 涨 2–48%。

    Personalized Showcases: Generating Multi-Modal Explanations for RecommendationsSIGIRMMCRS2023

    提出“个性化展示”新任务，用 DPP 选图 + GPT-2 多模态解码生成图文解释，以跨模态/个性化对比学习提升多样性与视觉对齐，Distinct-2 提升近 5 倍。

    Where to Go Next for Recommender Systems? ID- vs. Modality-based Recommender Models RevisitedSIGIRMMCold2023

    以统一骨干/采样/损失公平对比 IDRec 与纯模态 MoRec，证明 SASRec+端到端微调下 MoRec 已在常规/暖物品场景追平或超越 IDRec，冷启动碾压但训练开销 >100×。

    ❄️ 冷启动与长尾推荐 (3)

    Editable User Profiles for Controllable Text RecommendationSIGIRColdLLM4Rec2023

    LACE以检索式概念瓶颈构建人类可读的用户画像，用最优传输计算个性化概念值进行文本推荐，在冷启动与零样本设定下NDCG@20较NeuKNN提升5–29%。

    MELT: Mutual Enhancement of Long-Tailed User and Item for Sequential RecommendationSIGIRColdSeq2023

    SIGIR 2023 长尾序列推荐：双边分支互增强+课程学习，联合提升尾用户/尾物品，Music 总体 HR@10 +8.3%。

    Uncertainty-aware Consistency Learning for Cold-Start Item RecommendationSIGIRColdSSL2023

    UCC 用不确定性伪交互生成与教师-学生一致性学习对齐冷/热物品分布，10-core/7:1:2、K=20 下 Recall 最高提升 27.6%。

    🌐 跨域与多场景推荐 (1)

    Hgformer: Hyperbolic Graph Transformer for RecommendationSIGIRCrossGraph2023

    双曲流形上的无参图卷积 + 线性化双曲交叉注意力，兼顾长尾局部结构与全局信息，全库排序下 Amazon-Book R@10 相对提升 17.6%。

    📍 时空轨迹与 POI 本地生活推荐 (2)

    Exploring the Spatiotemporal Features of Online Food Recommendation ServiceSIGIRPOICTR2023

    系统剖析外卖场景时空特征价值，指出 self-attention 不适用的根因，提出时间差特征与动态上下文自适应模块 DCAM，离线 AUC 与线上 CTR 双赢

    Model-Agnostic Decentralized Collaborative Learning for On-Device POI RecommendationSIGIRPOIDebias2023

    MAC 允许端侧 POI 推荐模型结构异构，用参考数据软决策+互信息蒸馏做去中心化协同，采样邻居降噪，1/6 模型体积下 HR@10 超 DCLR 3.8%

    🎯 CTR/CVR 预估与特征交叉 (3)

    Contrastive Learning for Conversion Rate PredictionSIGIRCTRSSL2023

    用嵌入掩码替代特征掩码构造对比视图，配合假负样本剔除与转化正样本纳入，缓解CVR稀疏，工业/公开集AUC+0.0079/+0.0066

    FedAds: A Benchmark for Privacy-Preserving CVR Estimation with Vertical Federated LearningSIGIRCTRDebias2023

    首个基于阿里真实广告日志的纵向联邦 CVR 基准，含 1130 万样本数据集、扩散式未对齐样本合成 (Diffu-AT) 与梯度 mixup+投影隐私防御 (MixPro) 的系统评测。

    Reformulating CTR Prediction: Learning Invariant Feature Interactions for RecommendationSIGIRCTRDebias2023

    按时间切分环境、解耦环境不变/特异嵌入做不变学习，剔除不稳定特征交叉；ML-10M/Douban 上 AUC 相对 FM 提升 1.63%/0.18%。

    ⚖️ 多任务学习与列表级重排 (1)

    Intent-aware Ranking Ensemble for Personalized RecommendationSIGIRMTLCTR2023

    提出 IntEL，用意图感知的物品级权重融合多目标异构列表，经误差-歧义分解理论保证，Tmall/LifeData 全目标 NDCG 显著提升。

    🎮 强化学习与动态探索推荐 (4)

    Alleviating Matthew Effect of Offline Reinforcement Learning in Interactive RecommendationSIGIRRLDebias2023

    指出离线 RL 的保守性惩罚会放大马太效应，提出熵惩罚项 DORL，在 KuaiRec/KuaiRand 交互环境中累计收益提升 79.3%。

    Causal Decision Transformer for Recommender Systems via Offline Reinforcement LearningSIGIRRLSeq2023

    以因果决策 Transformer 将离线推荐改写为轨迹序列建模，绕开奖励函数手工设计，在 6 个真实数据集与 VirtualTB 模拟器上取得召回/CTR 领先。

    Contrastive State Augmentations for Reinforcement Learning-Based Recommender SystemsSIGIRRLSSL2023

    用四种局部状态增广平滑离线 RL 的 Q 值面，并对增广视图施加对比损失，在三个数据集与模拟在线环境中稳定提升序列推荐收益。

    RL4RS: A Real-World Dataset for Reinforcement Learning based Recommender SystemSIGIRRLDebias2023

    发布首个开源真实工业级 RL 推荐数据集（Slate/SeqSlate），配套四层评估框架与数据理解工具；PPO 线上 GMV 较 DIEN 提升 23.9%。

    🛡️ 去偏公平、可信隐私与工业架构 (9)

    Attacking Pre-trained RecommendationSIGIRDebiasSeq2023

    揭示预训练序列推荐模型提供者可植入后门，提出基础替换与提示增强攻击，在 Leave-One-Out 协议下将目标物品曝光率提升数百倍且保持隐蔽。

    COUPA: An Industrial Recommender System for Online to Offline Service PlatformsSIGIRDebiasPOI2023

    用连续时间点过程+个性化位置选择器联合建模 O2O 场景的时间周期性与位置偏置，Alipay 线上 CTR 提升 2.47%–5.63%。

    FairDiff: Mitigating the Self-Reinforcing Matthew Effect in Diffusion Recommender ModelsSIGIRDebiasGenRec2023

    揭示扩散推荐模型优化偏置+先验失配叠加的自强化马太效应，用推理期流行度条件引导与最优传输语义校准即插即用地同时提升精度与长尾公平。

    Inference at Scale: Significance Testing for Large Search and Recommendation ExperimentsSIGIRDebias2023

    用 Copula 模拟实证 5 种成对显著性检验：大样本下 Sign/Wilcoxon 一类错误率严重膨胀，功效全部饱和至 100%，应改用效应量判据。

    JDsearch: A Personalized Product Search Dataset with Real Queries and Full InteractionsSIGIRDebiasCold2023
