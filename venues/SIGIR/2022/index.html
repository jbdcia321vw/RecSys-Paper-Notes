    🏛️ SIGIR 2022 推荐系统论文解读

    57 篇 SIGIR 2022 论文解读，覆盖 11 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🔥 高频主题： CTR预估与特征交叉 ×4 · 跨视图对比学习 ×3 · 去偏公平与工业架构 ×2 · 知识图谱推荐 ×2 · 离线强化学习 ×2 · 端到端生成式 ×2

    🤝 协同过滤与双塔召回 (4)

    AutoLossGen: Automatic Loss Function Generation for Recommender SystemsSIGIRCFCTR2022

    用 RNN 控制器在基础算子空间上以 RL 从零搜索损失函数，配合代理测试与奖励过滤克服稀疏奖励，生成 MaxR/SumR 在 AUC 上稳定超过 MSE/BCE/Hinge/Focal。

    Enhancing Top-N Item Recommendations by Peer CollaborationSIGIRCFSeq2022

    提出 PCRec：两个同构推荐模型按层熵/范数度量冗余并互相移植权重，在推理零额外开销下稳定提升 Top-N 精度

    INMO: A Model-Agnostic and Scalable Module for Inductive Collaborative FilteringSIGIRCFCold2022

    用模板用户/物品作基向量、由交互集合线性生成用户/物品嵌入，为 MF/LightGCN 注入归纳能力并大幅压缩参数量；直推与两种归纳场景全面领先。

    MP2: A Momentum Contrast Approach for Recommendation with Pointwise and Pairwise LearningSIGIRCFSSL2022

    用三塔结构+动量物品塔平滑表示、以双塔差异度重加权逐点标签，联合逐点/成对损失缓解隐式反馈标注偏置，NDCG@5 相对最优基线提升 1.3–3.2%。

    🕸️ 图神经网络与知识图谱推荐 (7)

    Graph Trend Filtering Networks for RecommendationsSIGIRGraphSSL2022

    用 L1 图趋势滤波替换拉普拉斯等权平滑，得到边级自适应加权的嵌入传播，Full-Ranking 下 NDCG@20 最高相对提升 12.77%。

    HAKG: Hierarchy-Aware Knowledge Gated Network for RecommendationSIGIRGraphCF2022

    将用户-物品图与知识图谱同时嵌入双曲空间，用双曲关系传递聚合、层级锥角约束与双物品嵌入门控融合，Full-Ranking 下 nDCG@20 最高提升 15.43%

    Hypergraph Contrastive Collaborative FilteringSIGIRGraphSSL2022

    参数化低秩超图学习刻画全局依赖 + 局部-全局跨视图 InfoNCE，缓解 GNN 过平滑与交互稀疏，Full-Ranking 下 NDCG@20 相对 LightGCN 提升 24.7%

    Knowledge Graph Contrastive Learning for RecommendationSIGIRGraphSSL2022

    以KG结构一致性为去噪信号指导交互图增广，跨视图对比学习在三个数据集全库排序下Recall@20 提升约4-6%。

    Less is More: Reweighting Important Spectral Graph Features for RecommendationSIGIRGraphCF2022

    谱域分析发现仅少数平滑/粗糙图特征有效，用指数核带通滤波的 GDE 替代邻域聚合，5 数据集全库排序最优且比 LightGCN 快 12 倍。

    Multi-level Cross-view Contrastive Learning for Knowledge-aware Recommender SystemSIGIRGraphSSL2022

    拆解用户-物品-实体图为协同/语义/结构三视图，做局部-全局跨视图对比学习，AUC 较 KGIN 提升 1.6–2.8 个百分点。

    Unify Local and Global Information for Top-$N$ RecommendationSIGIRGraphCF2022

    提出双分支 KADM：协同注意力编码局部交互、关系感知 GNN 编码包围子图，门控融合后在 1:100 采样排序下 Recall@20 提升 3.1%~7.3%。

    🔄 自监督对比学习与交互去噪 (4)

    A Review-aware Graph Contrastive Learning Framework for RecommendationSIGIRSSLGraph2022

    将评分+评论构建为边特征增强的用户-物品图，用评论调制邻居权重，并以节点/边判别双对比任务提供自监督信号；在5个5-core数据集上随机划分、MSE指标取得最高4.2%相对提升。

    Are Graph Augmentations Necessary? Simple Graph Contrastive Learning for RecommendationSIGIRSSLGraph2022

    实验揭示InfoNCE带来的表示均匀性而非图增强是增益关键，提出嵌入空间加均匀噪声的SimGCL；三数据集全库排序下Recall@20较LightGCN最高提升25.6%。

    Improving Micro-video Recommendation via Contrastive Multiple InterestsSIGIRSSLSeq2022

    用隐式正交类别解耦多兴趣，并以跨视图对比多兴趣损失抵御微视频自动播放的假阳性噪声，双数据集 Recall@20 提升 24%/1.7%。

    Self-Guided Learning to Denoise for Robust RecommendationSIGIRSSLDebias2022

    利用推荐模型早期“抗噪期”的记忆效应收集干净样本，以元学习方式学出自适应重加权函数指导后续训练，模型无关地提升 Recall@20 最多 15%。

    ⏱️ 序列与会话推荐 (12)

    Ada-Ranker: A Data Distribution Adaptive Ranking Paradigm for Sequential RecommendationSIGIRSeqCross2022

    以 Neural Process 提取候选集分布 z，经 FiLM 输入调制与参数池补丁调制，把全局精排器即时改写为局部模型，NDCG 平均提升约 2.5%，新分布下增益达 15.5%。

    Coarse-to-Fine Sparse Sequential RecommendationSIGIRSeqCold2022

    显式建模类目/卖家意图序列作为稠密先验，与物品序列双编码器融合并按联合概率解码，稀疏数据上 NDCG@5 相对提升 44.03%。

    Decoupled Side Information Fusion for Sequential RecommendationSIGIRSeq2022

    将侧信息从输入层移至注意力层解耦计算，配合辅助属性预测器，在四个 Amazon/Yelp 数据集全库排序上稳定超越 SASRec/NOVA/ICAI-SR。

    Denoising Time Cycle Modeling for RecommendationSIGIRSeqCTR2022

    DiCycle 用绝对/相对时间核编码 + 门控去噪分别刻画 ATC/RTC 两种周期模式，CTR 预测在 LastFM/ML-1M/Books/工业集上 AUC 稳定超越时序基线。

    Determinantal Point Process Likelihoods for Sequential RecommendationSIGIRSeqMTL2022

    用 DPP 集合似然替换逐点/成对损失，把「下 T 项」建模为集合抽取，即插即用于 Caser/MARank/SASRec，Beauty Recall@3 最高 +37%。

    ELECRec: Training Sequential Recommenders as DiscriminatorsSIGIRSeqSSL2022

    借鉴 ELECTRA 思想，将序列推荐从下一项生成改为真假判别训练，辅助生成器采样难负例，四数据集 Full-Ranking 下 HR@5 提升 38%–137%。

    Exploiting Session Information in BERT-based Session-aware Sequential RecommendationSIGIRSeqSSL2022

    在 BERT4Rec 输入层以会话标记、会话段嵌入与时间感知自注意力三种轻量插件注入会话结构，仅增 0.1% 参数即在全库排序下取得最高 55% NDCG 提升。

    FUM: Fine-grained and Fast User Modeling for News RecommendationSIGIRSeq2022

    将用户点击新闻拼接成一条长文档，用 Fastformer 线性复杂度捕获词级跨新闻交互，并融合新闻级粗粒度通路；MIND/Feeds 上 AUC 相对提升 2.2%–2.5%，推理仅 2.75s/1k 样本。

    Is News Recommendation a Sequential Recommendation Task?SIGIRSeq2022

    论证新闻推荐非标准序列任务，提出双序无关 Transformer 与时间多样性惩罚 TempRec，在 MIND/News 曝光排序稳定提升 AUC/nDCG。

    News Recommendation with Candidate-aware User ModelingSIGIRSeq2022

    用候选新闻反向引导用户建模，Candi-SelfAtt/Candi-CNN/Candi-Att 三路聚合，MIND 上 nDCG@5 相对提升 4.2%

    🗣️ 对话推荐与智能体仿真 (2)

    Analyzing and Simulating User Utterance Reformulation in Conversational Recommender SystemsSIGIRCRS2022

    基于用户研究提出重述序列生成任务，用类型引导 T5/BART 与阅读难度过滤提升模拟用户拟人度。

    User-Centric Conversational Recommendation with Multi-Aspect User ModelingSIGIRCRSSSL2022

    将历史对话会话与相似用户引入 CRS，用多视图自监督对齐与时序 look-alike 选择器实现以用户为中心建模，全库排序下 HR@10 相对提升 21.5%。

    👥 社交与群组推荐 (1)

    Thinking inside The Box: Learning Hypercube Representations for Group RecommendationSIGIRSocialSSL2022

    用中心-偏移超立方体替代点向量表示群组，配内外双重距离与组交集自监督，全库排序下 Recall@10 平均超 GroupIM 14.4%。

    📍 时空轨迹与 POI 本地生活推荐 (2)

    Empowering Next POI Recommendation with Multi-Relational ModelingSIGIRPOIGraph2022

    MEMO 用多关系 GCN + 关系专属自注意力聚合异构社交图，并以耦合 RNN 建模用户-POI 时序互影响；在三个 LBSN 数据集 Recall@10 相对 STAN 提升约 2.7%–3.0%。

    GETNext: Trajectory Flow Map Enhanced Transformer for Next POI RecommendationSIGIRPOIGraph2022

    构建用户无关的全局轨迹流图并用 GCN+转移动注意力图显式编码群体转移模式，融合 Transformer 序列建模，在 NYC/TKY/CA 全库排序上 Acc@5 提升约 11%。

    🎯 CTR/CVR 预估与特征交叉 (6)

    Adversarial Filtering Modeling on Long-term User Behavior Sequences for Click-Through Rate PredictionSIGIRCTRSeq2022

    用分层聚合压缩重复行为、自注意力打分门选 top-k 行为，并以对抗训练（IEU 最小化、BSU 最大化剩余序列损失）剔除长序列噪声行为，工业集 AUC +0.0047、线上 CTR +4.7%。

    Enhancing CTR Prediction with Context-Aware Feature Representation LearningSIGIRCTR2022

    FRNet 通过比特级门控融合原始特征与互补特征，为每条样本生成上下文感知的特征表示，即插即用并显著提升多种 CTR 模型。

    HIEN: Hierarchical Intention Embedding Network for Click-Through Rate PredictionSIGIRCTRGraph2022

    用属性树自底向上聚合 + 层次注意力双向意图建模精修Embedding，作为即插即用输入模块，在阿里/Tmall/腾讯三个数据集上AUC较DG-ENN最高提升0.86%。

    Neighbour Interaction based Click-Through Rate Prediction via Graph-masked TransformerSIGIRCTRGraph2022

    将 CTR 重建为异构信息图上 user-item 局部邻域连边预测，用四类交互图 + 头分组图掩码 Transformer 编码邻域，微信线上 CTR +21.9%。

    Posterior Probability Matters: Doubly-Adaptive Calibration for Neural Predictions in Online AdvertisingSIGIRCTRDebias2022

    提出 AdaCalib，用后验统计引导的分段线性保序函数族做字段级概率校准，并以频率驱动的自适应分箱匹配字段取值，Field-RCE 相对降 10%~70%，线上 CVR +5.05%。

    Single-shot Embedding Dimension Search in Recommender SystemSIGIRCTRDebias2022

    SSEDS 用一次前向-反向的梯度显著性打分完成字段级嵌入维度剪枝，90% 参数下 AUC 反升，并在微信订阅号 A/B 提升约 4% CTR。

    ⚖️ 多任务学习与列表级重排 (1)

    Multi-Level Interaction Reranking with User Behavior HistorySIGIRMTLCTR2022

    MIR 将候选集视为无序集合、用户历史视为时序列表，用 SLAttention 做 set2list 跨层交互并保证排列不变性，三数据集全指标超越 SOTA。

    🎮 强化学习与动态探索推荐 (4)

    Rethinking Reinforcement Learning for Recommendation: A Prompt PerspectiveSIGIRRLSeq2022

    将离线 RL 推荐从「状态-动作→Q 值」翻转为「状态-累计回报→动作」的提示式监督学习，全库排序下购买 HR@5 最高 +13.0%。

    State Encoders in Reinforcement Learning for Recommendation: A Reproducibility StudySIGIRRLSeq2022

    用去偏 SOFA 模拟器+ DQN 复现“注意力状态编码器最优”结论，发现该结论在 Yahoo! R3 成立但在 Coat 数据集失效，无单一最优编码器。

    Towards Validating Long-Term User Feedbacks in Interactive Recommendation SystemsSIGIRRL2022

    复检 RL 交互推荐基准，发现公共评论数据集长期效应微弱：贪心单步奖励模型 (γ=0) 反超 RL，beam 与 greedy 差距 <1.5%。

    Value Penalized Q-Learning for Recommender SystemsSIGIRRLSeq2022

    提出乘性不确定性惩罚 VPQ，用 Q 集成方差构造 $p$-mul 保守目标并配 critic 框架，在两数据集上为三种序列模型平均带来 6–9% 相对增益。

    🛡️ 去偏公平、可信隐私与工业架构 (14)

    BARS: Towards Open Benchmarking for Recommender SystemsSIGIRDebiasCTR2022

    提出含 7 项标准产物的开放基准流水线，固化数据划分与评测协议 ID，在 6 数据集 70+ 模型上完成 8000+ 次全库排序与 CTR 复现实验，揭示近年增益被系统性夸大。

    CPFair: Personalized Consumer and Producer Fairness Re-ranking for Recommender SystemsSIGIRDebiasMTL2022

    用加性贪心重排把用户侧与物品侧公平偏差同时作为软惩罚，8 数据集上 mCPF 平均降 12.8%~46.9% 且精度不降。

    Experiments on Generalizability of User-Oriented Fairness in Recommender SystemsSIGIRDebias2022

    系统复现并泛化评估用户公平重排 UFR：8 数据集 6 基础模型 2 分组，揭示领域/分组/基模型依赖与公平-效用权衡。

    Explainable Fairness in RecommendationSIGIRDebias2022

    提出反事实可解释公平框架 CEF，用最小特征扰动解释曝光不公平，并在三数据集擦除评测中取得更优公平-效用权衡。

    Investigating Accuracy-Novelty Performance for Graph-based Collaborative FilteringSIGIRDebiasGraph2022

    理论证明 GNN 对称归一化是流行度偏置之源，提出零开销插件 r-AdjNorm，通过单一系数 r 控制归一化强度，在三个基准上不损精度的同时显著提升新颖性。

    Joint Multisided Exposure Fairness for RecommendationSIGIRDebias2022

    提出六类用户-物品双侧群体曝光公平指标，分解差异/相关性，并用可微 Plackett-Luce 随机排序优化 GG-F。

    On Natural Language User Profiles for Transparent and Scrutable RecommendationSIGIRDebiasLLM4Rec2022

    提出以自然语言用户画像替代稠密向量作为推荐的唯一中间表示，分解为画像生成与 NL 推荐两步，并用 LaMDA 少样本提示做定性可行性验证。

    Privacy-Preserving Synthetic Data Generation for Recommendation SystemsSIGIRDebiasGenRec2022

    UPC-SDG 用贡献度感知选择+Gumbel-Softmax 可微生成，按用户隐私偏好(k,γ)替换原始交互，兼顾数据/物品双层隐私与效用。

    ProFairRec: Provider Fairness-aware News RecommendationSIGIRDebias2022

    提出公平/偏置表征解耦、对抗学习与正交正则，在MIND上提升新闻提供者曝光公平且精度基本持平

    Regulating Group Exposure for Item Providers in RecommendationSIGIRDebiasMTL2022

    SIGIR 2022 短文，将供应商按敏感属性分组，提出基于 Hellinger 距离与 MMR 的贪心重排序，使推荐曝光贴合平台指定目标分布，在几乎不损失 NDCG 的前提下显著提升少数群体曝光与列表级多样性/新颖性。
