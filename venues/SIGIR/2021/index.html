    🏛️ SIGIR 2021 推荐系统论文解读

    40 篇 SIGIR 2021 论文解读，覆盖 13 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🔥 高频主题： CTR预估与特征交叉 ×2 · 元学习 ×2 · 冷启动 ×2 · 图对比学习 ×2

    🏷️ 标签筛选 仅显示 ≥2 篇论文的标签；默认 AND

    🤝 协同过滤与双塔召回 (7)

    Bootstrapping User and Item Representations for One-Class Collaborative FilteringSIGIRCFSSL2021

    BUIR 用在线/目标双编码器互预测替代负采样, 配合邻居随机丢弃增广, 在极稀疏隐式反馈上 Full-Ranking P@10 相对最优基线提升 22.8%–58.7%。

    Cross-Batch Negative Sampling for Training Two-Tower RecommendersSIGIRCFSSL2021

    利用编码器 embedding stability，以 FIFO memory bank 复用历史 batch 的 item 向量作为跨批次负样本，在几乎零额外编码开销下把负样本量从 128 扩至 2560，NDCG@50 最高提升 12.19%。

    Neural Graph Matching based Collaborative FilteringSIGIRCFGraph2021

    将属性交互解耦为内交互与交叉交互，用双属性图匹配结构分别做特征学习与偏好匹配，AUC/NDCG@10 最高提升 4.3%/16.5%。

    Neural Representations in Hybrid Recommender Systems: Prediction versus RegularizationSIGIRCF2021

    论证混合推荐中神经表征应直接用于打分而非充作正则项，删去 MF 表征与解码器后 RMSE 降 3.8% 且训练更快、内存更省。

    Path-based Deep Network for Candidate Item Matching in RecommendersSIGIRCFGraph2021

    用 TrigNet×SimNet 对用户-物品二跳路径逐条打分并聚合召回，兼顾个性化与兴趣多样性，淘宝线上 PCTR +18.04%。

    Scalable Personalised Item Ranking through Parametric Density EstimationSIGIRCFSSL2021

    以指数族参数密度估计推导点式排序风险与最优负采样分布（排序器自采样、免额外生成器），配合范数裁剪稳定训练；Full-Ranking 下 nDCG@20 较 DREGN-CF 最高 +18%，收敛快 1–2 个数量级。

    Set2setRank: Collaborative Set to Set Ranking for Implicit Feedback based RecommendationSIGIRCF2021

    提出集合到集合两级排序损失，结合自适应掩码负采样，在Full-Ranking下提升隐式反馈Top-N推荐。

    🕸️ 图神经网络与知识图谱推荐 (3)

    Graph Meta Network for Multi-Behavior RecommendationSIGIRGraphMTL2021

    用元学习为每个用户动态生成行为异质变换与预测层参数，联合建模多行为图传播与跨类型依赖；Leave-One-Out + 1:99 采样排序下，Taobao HR@10 相对 NGCF_M 提升 31.3%。

    Personalized News Recommendation with Knowledge-aware Interactive MatchingSIGIRGraph2021

    KIM 用知识协同编码器与语义协同编码器实现候选新闻与用户兴趣的双向交互匹配，在 MIND/Feeds 上 nDCG@5 相对提升约 5%。

    UGRec: Modeling Directed and Undirected Relations for RecommendationSIGIRGraphCold2021

    将知识图谱有向关系与物品共现无向关系统一建模：有向关系用 TransD 关系空间投影+头尾关系感知注意力，无向关系用关系专属超平面投影最小化距离，Amazon 三数据集 Leave-One-Out 全库排序下 HR@20 相对 SOTA 提升 3.7%–5.4%。

    🔄 自监督对比学习与交互去噪 (2)

    Self-supervised Graph Learning for RecommendationSIGIRSSLGraph2021

    在 LightGCN 上叠加节点自判别对比任务，用节点/边丢弃与随机游走构造多视图，全库排序下 Recall@20 最高提升 9.13%。

    Topology-aware Debiased Self-supervised Graph Learning for RecommendationSIGIRSSLGraph2021

    用交互共现拓扑筛选假阴性并转为辅助正样本，在三个数据集 Full-Ranking 下 Recall@20 最高相对提升约 3.1%。

    ⏱️ 序列与会话推荐 (4)

    CauseRec: Counterfactual User Sequence Synthesis for Sequential RecommendationSIGIRSeqSSL2021

    通过反事实概念替换合成用户序列并做对比学习，使用户表征对噪声不敏感、对关键兴趣更信任；Amazon Books NDCG@50 相对最强基线提升 22.1%。

    Learning a Fine-Grained Review-based Transformer Model for Personalized Product SearchSIGIRSeqCold2021

    将查询、用户评论与物品评论拼成单序列交给 Transformer 做评论级细粒度匹配，Amazon 三品类 BM25 候选重排 MRR 最高相对提升 60%，并天然支持注意力可解释与动态个性化。

    Sequential Recommendation with Graph Neural NetworksSIGIRSeqGraph2021

    将松散物品序列用度量学习重构为兴趣图，经簇/查询双感知图卷积与动态图池化提炼激活核心兴趣，长序列场景 AUC 提升约 4%。

    Unsupervised Proxy Selection for Session-based Recommender SystemsSIGIRSeqCF2021

    用可学习的 K 个代理在无监督下为匿名会话选择"用户长期兴趣"，结合短期兴趣与超平面投影距离，全库排序 R@20 相对提升最高 45.4%。

    🧠 大语言模型推荐 (LLM4Rec) (1)

    Empowering News Recommendation with Pre-trained Language ModelsSIGIRLLM4RecSeq2021

    用 PLM 替换新闻编码器并以 Attention 池化 token 隐状态、仅微调顶层两层，MIND 上 AUC 68.18→70.64，多语言 7 市场 AUC 61.07→62.83，线上点击 +8.53%/+10.68%。

    🗣️ 对话推荐与智能体仿真 (3)

    Comparison-based Conversational Recommender System with Relative Bandit FeedbackSIGIRCRSRL2021

    提出 RelativeConUCB，用成对 key-term 相对反馈与差异岭回归更新偏好；真实数据漂移场景累积遗憾较 ConUCB 降低 44.75%–49.96%。

    Learning to Ask Appropriate Questions in Conversational RecommendationSIGIRCRSGraph2021

    KBQG 用 KG 关系注意力引导澄清问题生成，简化动作空间后在两数据集上 SR 相对 CRM 提升 7.2%–12.9% 且显著缩短对话轮次

    On Interpretation and Measurement of Soft Attributes for RecommendationSIGIRCRSDebias2021

    将软属性批评表示为相对锚点物品的个性化偏序，用去偏众包与加权 Gamma 度量，并以无/弱/全监督三档打分器实现属性排序。

    👥 社交与群组推荐 (2)

    ConsisRec: Enhancing GNN for Social Recommendation via Consistent Neighbor AggregationSIGIRSocialGraph2021

    提出一致性查询+邻居采样+关系注意力，抑制社交图中上下文级与关系级不一致噪声，在 Ciao/Epinions 评分预测上 RMSE 相对降 2.79%/1.74%。

    Group based Personalized Search by Integrating Search Behaviour and Friend NetworkSIGIRSocialSeq2021

    FNPS 用“关系圈+行为圈”双通道好友分组与掩码交叉注意力构建群体画像，在微信搜索日志重排上 MAP 较原始排序 +3.22%。

    ❄️ 冷启动与长尾推荐 (4)

    Learning Graph Meta Embeddings for Cold-Start Ads in Click-Through Rate PredictionSIGIRColdCTRGraph2021

    用广告属性图 + GAT + MAML 式元学习为新广告 ID 生成初始嵌入，在三个真实数据集上对五种 CTR 主干模型实现冷启动与预热双阶段 AUC 提升。

    Learning to Warm Up Cold Item Embeddings for Cold-start Recommendation with Meta Scaling and Shifting NetworksSIGIRColdCTR2021

    用元缩放/平移网络将冷物品 ID 嵌入变换到热特征空间并以交互用户均值去噪，三点数据集八基线 + 六基础模型上 AUC 显著提升。

    Privileged Graph Distillation for Cold Start RecommendationSIGIRColdGraph2021

    将属性作为节点构建异质图教师模型，用二阶间接链接构造无 CF 边的学生图，通过特权图蒸馏实现新用户/新物品/双冷启动统一推荐，Yelp/XING/Amazon 全库排序 HR/NDCG 平均最高提升 27.8%。

    Sequential Recommendation for Cold-start Users with Meta Transitional LearningSIGIRColdSeq2021

    将冷启动序列推荐重构为少样本任务，用翻译式转移编码器 + MAML 双层优化实现仅 K=2~4 次交互即可快速适配，时间戳冷启动划分下 Hit@1/MRR 显著超越 SASRec/BERT4Rec/MetaCF。

    🌐 跨域与多场景推荐 (1)

    Transfer-Meta Framework for Cross-domain Recommendation to Cold-Start UsersSIGIRCrossCold2021

    用全量预训练替代重叠用户重训，并以 MAML 式任务导向元网络隐式迁移源域用户表征，6 个跨域冷启动任务 AUC 最高提升 4.8%。

    📍 时空轨迹与 POI 本地生活推荐 (1)

    POINTREC: A Test Collection for Narrative-driven Point of Interest RecommendationSIGIRPOICold2021

    构建 695K POI + 112 条真实自然语言叙事需求的冷启动 POI 测试集，配众包 4 级相关性池化标注与三种结构化查询基线，NDCG@5 最优 0.6784。

    🎯 CTR/CVR 预估与特征交叉 (5)

    AdsGNN: Behavior-Graph Augmented Relevance Modeling in Sponsored SearchSIGIRCTRGraph2021

    以点击二部图作互补信号，在节点/边/Token 三级融合语义与行为图，配合领域预训练与长尾蒸馏，ROC-AUC 0.881、线上 RPM +1.13%。

    Deep Position-wise Interaction Network for CTR PredictionSIGIRCTRDebias2021

    DPIN 将候选物品与展示位置解耦为 item 塔与 position 塔并行打分，训练与推理一致地用真实位置建模，并提出 PAUC 指标；线上 A/B 提升 CTR 2.25%、RPM 2.15%。

    Enhanced Doubly Robust Learning for Debiasing Post-click Conversion Rate EstimationSIGIRCTRDebias2021

    从 DR 估计量的偏差-方差分解出发，把误差插补目标改为最小化方差并引入双学习伪标签机制，CVR 去偏在 Coat/Yahoo!R3 全排序评测上稳定超越 IPS 与 DR-JL。

    Looking at CTR Prediction Again: Is Attention All You Need?SIGIRCTR2021

    用离散选择模型重构 CTR 目标，提出 ST∘AL∘FI∘EL 统一框架与自注意力二阶算子 SAM 族，Criteo/Avazu 上 SAM2E 取最优 AUC 0.8115/0.7891。

    ScaleFreeCTR: MixCache-based Distributed Training System for CTR Models with Huge Embedding TableSIGIRCTRDebias2021

    用 VSI 批内去重、GPU HBM 混合缓存 MixCache 与三阶段流水线消除 Host↔GPU 参数搬运延迟，Criteo-TB 上训练吞吐达 PS 的 1.6×/1.3×、HugeCTR 的 5.6×/6.9×。

    ⚖️ 多任务学习与列表级重排 (1)

    New Insights into Metric Optimization for Ranking-based RecommendationSIGIRMTLCF2021

    系统比较 RR/AP/nDCG/RBP 作为 pairwise 与 listwise 优化目标，提出 RBP 损失，揭示优化指标≠评估指标更优。

    🛡️ 去偏公平、可信隐私与工业架构 (6)

    AutoDebias: Learning to Debias for RecommendationSIGIRDebias2021

    将各类数据偏置统一为风险差异，用小型无偏数据以元学习双层优化自动学习重加权/插补参数，Yahoo!R3 NDCG@5 提升 11.2%。

    Causal Intervention for Leveraging Popularity Bias in RecommendationSIGIRDebiasCF2021

    将物品流行度识别为曝光-交互之间的混杂因子，用 do-calculus 解耦训练并在推理期反向注入期望流行度，Kwai 上 Recall@20 相对 BPRMF 提升约 165%。

    Clicks can be Cheating: Counterfactual Recommendation for Mitigating Clickbait IssueSIGIRDebiasMTL2021

    在因果图中补入曝光→打分直连边，反事实扣除曝光的 NDE，仅用点击数据即把 N@10 提升 7.5%–11.1%。

    Counterfactual Explanations for Neural RecommendersSIGIRDebiasCRS2021

    ACCENT 将影响函数从单点扩展到「推荐项-替代项」点对，迭代填平分数差生成最小反事实解释集，重训验证下解释集规模比 FIA 缩小约 1.5–1.7 倍。

    EXTRA: Explanation Ranking Datasets for Explainable RecommendationSIGIRDebiasCRS2021

    用 MinHash-LSH 将近重复评论句折叠为全局解释库，构造三个(user,item,explanation)三元组基准，把可解释推荐评测统一为解释全库排序。

    TFROM: A Two-sided Fairness-Aware Recommendation Model for Both Customers and ProvidersSIGIRDebiasMTL2021

    提出双边公平后处理重排模型 TFROM：位置敏感曝光 + 质量升序贪心填位，离线/在线两版在三数据集上以 <10% 质量损失大幅降低提供者曝光方差。
