    57 篇 SIGIR 2024 论文解读，覆盖 14 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🤝 协同过滤与双塔召回 (4)

    Behavior Pattern Mining-based Multi-Behavior RecommendationSIGIRCFGraph2024

    以行为模式路径计数为特征、贝叶斯似然比闭式打分替代GNN，在三个电商数据集Full-Ranking下Recall@10最高提升393.98%。

    Behavior-Contextualized Item Preference Modeling for Multi-Behavior RecommendationSIGIRCFSSL2024

    提出 BCIPM：用「行为上下文化物品偏好网络」只从目标行为聚合物品级偏好做推荐，辅助行为仅参与参数训练以规避噪声；四个数据集 Leave-One-Out + Full-Ranking 下 HR@10 相对提升 12.15%–26.48%。

    MealRec$^+$: A Meal Recommendation Dataset with Meal-Course Affiliation for Personalization and HealthinessSIGIRCF2024

    SIGIR 2024｜协同过滤与双塔召回｜构建含餐食-菜品关联与FSA/WHO健康分的MealRec⁺数据集，全库排序下CrossCBR Recall@20提升72.1%。

    To Search or to Recommend: Predicting Open-App Motivation with Neural Hawkes ProcessSIGIRCFSeq2024

    用神经 Hawkes 过程+层级 Transformer 建模用户开屏动机，OAMD 上 F0.5 提升 2.9%、AUC 达 0.9326

    🕸️ 图神经网络与知识图谱推荐 (8)

    AFDGCF: Adaptive Feature De-correlation Graph Collaborative Filtering for RecommendationsSIGIRGraphCF2024

    揭示 GNN-CF 中被忽视的“特征过相关”问题并证明其与过平滑成正比，提出层级自适应的列相关惩罚正则，模型无关地提升 4 类骨干模型最多 14.98%。

    GPT4Rec: Graph Prompt Tuning for Streaming RecommendationSIGIRGraphSeq2024

    将演化交互图解耦为多视图，用节点/结构/视图三级轻量图提示替代回放与模型扩张，实现流式推荐持续学习，R@20 最高相对提升 4.16%。

    Lightweight Embeddings for Graph Collaborative FilteringSIGIRGraphCF2024

    以可学习稀疏分配矩阵替代固定哈希映射，在扩展图上联合优化元嵌入码本，实现 44× 参数压缩下接近全量嵌入的精度。

    Masked Graph Transformer for Large-Scale RecommendationSIGIRGraphCF2024

    纯 Transformer 全节点注意力 + SimRFs 线性核 + 可学习相对度数掩码，Full-Ranking 下 Recall@20 最高提升 8.62%

    NFARec: A Negative Feedback-Aware Recommender ModelSIGIRGraphSeq2024

    以反馈极性引导超图卷积消息通路并用 Transformer Hawkes 过程辅助预测下一交互情感极性，五数据集全库排序 R@20 最高提升 6.6%、N@20 提升 14.2%

    SIGformer: Sign-aware Graph Transformer for RecommendationSIGIRGraphCF2024

    用Transformer直接建模整张符号图，以符号谱/路径编码融合正负反馈，五数据集Recall@20最高提升15.61%。

    TransGNN: Harnessing the Collaborative Power of Transformers and Graph Neural Networks for Recommender SystemsSIGIRGraphSeq2024

    交替堆叠 Transformer 与 GNN 层，用注意力采样+三种结构位置编码互相扩感受野与注入拓扑，全库排序下 Recall@20 最高提升 21%。

    Turbo-CF: Matrix Decomposition-Free Graph Filtering for Fast RecommendationSIGIRGraphCF2024

    用多项式图滤波器替代特征分解实现免训练免分解的协同过滤，全库排序下精度持平SOTA而耗时降至亚秒级。

    🔄 自监督对比学习与交互去噪 (1)

    Denoising Diffusion Recommender ModelSIGIRSSLGenRec2024

    用扩散前向-逆向过程对任意后端模型的用户/物品嵌入做多步去噪，以协同信息为引导、以历史偏好均值为推理起点，三数据集全排序 R@10 最高提升 25.2%。

    ⏱️ 序列与会话推荐 (12)

    Are We Really Achieving Better Beyond-Accuracy Performance in Next Basket Recommendation?SIGIRSeqDebias2024

    提出TREx解耦重复/探索商品，用简单重复模块保精度、探索模块提升公平/多样性，并批判现有beyond-accuracy评测可被“走捷径”。

    Disentangling ID and Modality Effects for Session-based RecommendationSIGIRSeqSSL2024

    DIMO 物品级把共现矩阵显式注入 ID 表征并将图文统一对齐到文本空间，会话级用代理机制与反事实推断无监督解耦 ID/模态成因，Cellphones Prec@20 较最优基线提升 55.12%。

    EulerFormer: Sequential User Behavior Modeling with Complex Vector AttentionSIGIRSeq2024

    用欧拉变换把语义差与位置差统一为复向量旋转角，配合自适应差分旋转与相位对比学习，SASRec 骨干 NDCG@10 最高提升 10.5%

    Interest Clock: Time Perception in Real-Time Streaming Recommendation SystemSIGIRSeqCTR2024

    将用户 24 小时分桶兴趣经高斯核按请求时间平滑聚合成兴趣时钟嵌入，抖音音乐线上 A/B 活跃天数 +0.509%、使用时长 +0.758%。

    Large Language Models for Intent-Driven Session RecommendationsSIGIRSeqLLM4Rec2024

    PO4ISR 用“提示初始化→自反思优化→跨域选择”三段式自动提示工程驱动 LLM 在语义层识别会话内变动数量的意图，20 候选重排下 HR/NDCG 平均提升 57.37%/61.03%。

    LLaRA: Large Language-Recommendation AssistantSIGIRSeqLLM4Rec2024

    将传统序列推荐器的 ID 行为嵌入经投影器对齐进 LLM 词元空间，用混合提示+课程学习实现行为模态注入，采样排序 HitRatio@1 最高提升 21.6%。

    Modeling User Fatigue for Sequential RecommendationSIGIRSeqSSL2024

    以兴趣感知相似度矩阵刻画目标-历史细粒度重复度，经 Cross 网络与疲劳门控 GRU 注入长短期兴趣，并用序列增广构造疲劳对比监督；Taobao AUC 提升 0.026，线上 EVTR 与类目多样性同升。

    Multi-intent-aware Session-based RecommendationSIGIRSeq2024

    MiaSRec 用位置+频次嵌入、highway 多意图表征与 α-entmax 动态意图筛选，配合 max/avg 双池化解码聚合，在六个数据集上全场刷新 SOTA，长会话 R@20 最高 +24.56%。

    Scaling Sequential Recommendation Models with TransformersSIGIRSeqCold2024

    用特征编码替代物品ID嵌入，使SRT参数与目录规模解耦，在Amazon全量数据上验证Transformer序列推荐的缩放律与预训练微调收益。

    SelfGNN: Self-Supervised Graph Neural Networks for Sequential RecommendationSIGIRSeqSSLGraph2024

    按时间切片构建短期协作图并用个性化自增强学习以长期兴趣矫正短期噪声，1:999 采样排序下四个数据集全面超越 17 个基线。

    ✨ 生成式推荐与离散语义 ID (2)

    Diffusion Models for Generative Outfit RecommendationSIGIRGenRecMM2024

    提出 GOR 新任务与 DiFashion，以类别提示、互条件、历史条件三路 CFG 引导套装多图并行扩散生成，iFashion FID 降低 19.8%。

    Graph Signal Diffusion Model for Collaborative FilteringSIGIRGenRecGraph2024

    用物品相似图上的热方程平滑替代高斯加噪作为前向扩散，反向用确定性去噪器做精修-锐化重建，三数据集全库排序 SOTA，Recall@20 最高 +5.44%。

    🧠 大语言模型推荐 (LLM4Rec) (3)

    Data-efficient Fine-tuning for LLM-based RecommendationSIGIRLLM4RecGenRec2024

    提出 DEALRec，用影响函数打分选取高影响力样本，以 2% 数据超越全量微调并降低 97% 训练耗时。

    Let Me Do It For You: Towards LLM Empowered Recommendation via Tool LearningSIGIRLLM4RecCRS2024

    提出 ToolRec，让 LLM 作为代理用户经属性检索/排序工具多轮探索物品池，并用记忆校验抑制幻觉；ML-1M/Amazon-Book 的 Recall@10 相对提升 3.36%/14.28%，Yelp 因本地知识不足退化。

    OpenP5: An Open-Source Platform for Developing, Training, and Evaluating LLM-based Recommender SystemsSIGIRLLM4RecGenRec2024

    开源P5式生成推荐平台，覆盖T5/Llama-2、10数据集、3种物品索引与序列/直推任务，T5+协同索引多数领先。

    🗣️ 对话推荐与智能体仿真 (3)

    MACRec: a Multi-Agent Collaboration Framework for RecommendationSIGIRCRSLLM4Rec2024

    以 Manager 为核心、Reflector 迭代反思、Analyst/Searcher 供工具的多智能体免训练协作框架，覆盖评分预测/序列推荐/对话推荐/解释生成四任务，仅给案例与演示 UI，无基准量化实验

    Minimizing Live Experiments in Recommender Systems: User Simulation to Evaluate Preference Elicitation PoliciesSIGIRCRSCold2024

    用反事实鲁棒的用户状态/会话生成器与生产级模拟器，在 YouTube Music 新用户引导场景中替代小样本在线实验，准确预测策略上线指标并正确排序候选策略。

    On Generative Agents in RecommendationSIGIRCRSLLM4Rec2024

    用 1000 个 LLM 生成式智能体构建推荐用户仿真器 Agent4Rec，以画像/记忆/动作三模块模拟真实用户，并复现信息茧房与因果结构。

    🧩 多模态推荐与内容理解 (1)

    Dataset and Models for Item Recommendation Using Multi-Modal User InteractionsSIGIRMMSeq2024

    发布保险场景多模态用户交互数据集，提出将对话与网页会话映射到共同特征空间以应对自然缺失模态，全库排序 MAP@3 较强基线提升 3.46%。

    ❄️ 冷启动与长尾推荐 (2)

    MIND Your Language: A Multilingual Dataset for Cross-lingual News RecommendationSIGIRCold2024

    构建14语言平行新闻推荐数据集xMIND，系统评测零样本/少样本跨语言迁移，揭示mPLM仍显著掉点。

    Multimodality Invariant Learning for Multimedia-Based New Item RecommendationSIGIRColdMM2024

    面向多模态新物品推荐，用跨模态对齐与循环 Mixup 构造缺失模态环境，IRM 学习不变用户偏好；新物品全库排序下 NDCG@20 最高提升约 17.5%。

    🌐 跨域与多场景推荐 (5)

    A Unified Search and Recommendation Framework Based on Multi-Scenario Learning for Ranking in E-commerceSIGIRCrossMTL2024

    用场景触发器驱动 S&R 双视角兴趣/特征抽取与对比解耦，并以全局标签条件概率做多任务，AUC 提升 0.08~0.62 点并落地 7Fresh。

    Aiming at the Target: Filter Collaborative Information for Cross-Domain RecommendationSIGIRCrossSSL2024

    以目标域用户相似度为显式约束，结合用户变换层与监督对比损失过滤源域协同信息，缓解跨域负迁移。

    M3oE: Multi-Domain Multi-Task Mixture-of-Experts Recommendation FrameworkSIGIRCrossMTL2024

    提出共享/域/任务三视角 MoE 与两级融合，并用 AutoML 双层优化自适应学习融合权重，解决多域多任务联合建模的 MDMT 跷跷板问题，MovieLens/KuaiRand 平均 AUC 相对提升 2.54%/5.48%。

    Pacer and Runner: Cooperative Learning Framework between Single- and Cross-Domain Sequential RecommendationSIGIRCrossSeq2024

    用停梯度非对称MoE解耦SDSR/CDSR以精确估计负迁移差，动态加权跨域损失并加互信息对齐，10个域上全面抑制负迁移，线上CTR+17.3%。

    UniSAR: Modeling User Transition Behaviors between Search and RecommendationSIGIRCrossSeq2024

    用掩码 Transformer 抽取 r2r/s2s/r2s/s2r 四类细粒度转移，对比对齐 + 交叉注意力融合，MMoE 联合训练统一搜索与推荐，双任务全面超越 SOTA。

    📍 时空轨迹与 POI 本地生活推荐 (3)

    Analyzing and Mitigating Repetitions in Trip RecommendationSIGIRPOISeq2024

    首次剖析行程推荐中POI重复生成的两大成因，提出循环感知预测器（引导矩阵+漂移惩罚+置信度自适应采样）在Flickr四城上兼顾精度与去重。

    OpenSiteRec: An Open Dataset for Site RecommendationSIGIRPOIGraph2024

    首个公开选址推荐数据集，用 5 类实体 9 类关系的异构图刻画 4 座国际都市，并在 5-core + 全库排序协议下基准测试 16 个推荐模型。

    Refine-POI: Reinforcement Fine-Tuned Large Language Models for Next Point-of-Interest RecommendationSIGIRPOILLM4Rec2024

    用层次自组织映射生成拓扑保序语义ID，并以GRPO列表级奖励替代SFT标签模仿，配合KL-Cov熵正则恢复有据推理，Acc@5最高提升12.1%。

    🎯 CTR/CVR 预估与特征交叉 (4)

    Breaking the Length Barrier: LLM-Enhanced CTR Prediction in Long Textual User BehaviorsSIGIRCTRLLM4Rec2024

    将 LLM 分层解耦为离线原子行为编码表 + 在线行为级交互，长序列 CTR 训练开销降 5 倍且 AUC 反升。

    Deep Pattern Network for Click-Through Rate PredictionSIGIRCTRSSL2024

    将 Target Attention 从 item 级拓宽到 pattern 级，用 target-aware 检索 + 自监督去噪精炼 + Target Pattern Attention 挖掘用户行为模式，三数据集 AUC 相对 CAN 提升 1.53%–2.95%。

    FedUD: Exploiting Unaligned Data for Cross-Platform Federated Click-Through Rate PredictionSIGIRCTRDebias2024

    用知识蒸馏把对齐样本上学到的 guest 表征迁移到 host 未对齐样本，让纵向联邦 CTR 的未对齐流量也能受益，AUC 提升约 0.7%。

    Neural Click Models for Recommender SystemsSIGIRCTRSeq2024

    将搜索侧神经点击模型迁移到 slate 推荐，以 readout 条件 GRU、对抗辅助损失与仅点击注意力建模曝光级用户响应，ContentWise AUC 相对提升 6.3%。

    🎮 强化学习与动态探索推荐 (4)

    Course Recommender Systems Need to Consider the Job MarketSIGIRRLLLM4Rec2024

    用 LLM 少样本技能抽取对齐 ESCO 岗位需求，将课程序列推荐建模为以「可申请岗位数」为奖励的 MDP，PPO 在长序列上以约 1/5 时延逼近贪心效果。

    EasyRL4Rec: An Easy-to-use Library for Reinforcement Learning Based Recommender SystemsSIGIRRLDebias2024

    构建五个真实数据集上的轻量 RL 推荐环境与统一长期收益评测管线（FreeB/NX_0_/NX_10_），系统复现 15+ 策略并揭示离散动作、On-Policy、偏好高估等关键结论。

    Large Language Models are Learnable Planners for Long-Term RecommendationSIGIRRLLLM4Rec2024

    用四个 LLM 实例构成宏/微双层可学习规划器，以外部记忆代替梯度更新，在模拟交互环境中显著提升轨迹长度与累计收益。

    Treatment Effect Estimation for User Interest Exploration on Recommender SystemsSIGIRRLDebias2024

    将Top-N类目曝光比视为多元连续处理，用IPW去偏ADRF/MTEF估计与动态规划优化兴趣探索，RCT评测R@10最高相对提升17.4%。

    🛡️ 去偏公平、可信隐私与工业架构 (5)

    CaDRec: Contextualized and Debiased Recommender ModelSIGIRDebiasGraph2024

    以超图卷积融合序列自注意力抑制过平滑，并用位置编码流行度与个体偏差双路解耦及梯度加权重整实现去偏，全库排序下 R@20 相对提升 4.2%–4.8%。

    Can We Trust Recommender System Fairness Evaluation? The Role of Fairness and RelevanceSIGIRDebias2024

    首次系统体检 9 个「相关性+公平」联合度量，用 4 数据集 × 4 推荐器 × 4 类探针揭示其互相矛盾、位置不敏感与分数压缩三大病灶。

    Leave No Patient Behind: Enhancing Medication Recommendation for Rare Disease PatientsSIGIRDebiasSSL2024
