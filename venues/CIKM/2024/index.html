    🏛️ CIKM 2024 推荐系统论文解读

    40 篇 CIKM 2024 论文解读，覆盖 14 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🔥 高频主题： 多模态推荐 ×4 · 端到端生成式 ×4 · 大语言模型推荐 ×3 · 知识蒸馏 ×2

    🏷️ 标签筛选 仅显示 ≥2 篇论文的标签；默认 AND

    🤝 协同过滤与双塔召回 (4)

    Ads Supply Personalization via Doubly Robust LearningCIKMCFDebias2024

    用 RCT 已知倾向分构造双稳健伪结局，轻量随机森林即可在长周期广告供给密度调控上把 CATE 估计与线上变现效率同时拉升。

    Feedback Reciprocal Graph Collaborative FilteringCIKMCFSSL2024

    按用户反馈将交互图拆为 I&F/I&U 双图分别做 GCF，用冲动性互惠对比与宏观聚类建模交换信息，全库排序下 Recall@20 平均提升 6.28%，淘宝 A/B GMV +1.61%。

    Improved Estimation of Ranks for Learning Item Recommenders with Negative SamplingCIKMCF2024

    将采样指标的二项校正迁移进 WARP/LambdaRank 训练，把串行 F-Rank 排名估计换成可批量并行校正估计，MSD 上 WARP Recall@20 相对提升 16.5%。

    Interpretable Triplet Importance for Personalized RankingCIKMCFSSL2024

    用三元组 Shapley 值可解释地度量 BPR 三元组重要性，蒙特卡洛+控制变量稳定估计并指导重采样，六数据集 R@20 平均提升约 9%。

    🕸️ 图神经网络与知识图谱推荐 (1)

    Quantum Cognition-Inspired EEG-based Recommendation via Graph Neural NetworksCIKMGraph2024

    以滑窗、量子认知塌缩和连续/干扰双图 GCN 学习 EEG 实时思维，MBD 采样 P@10 较 BPR 最高提升 95.7%。

    ⏱️ 序列与会话推荐 (8)

    A Universal Sets-level Optimization Framework for Next Set RecommendationCIKMSeqMTL2024

    用结构化行列式点过程 (SDPP) 将时序集合整体视为元素并设计集合级条件似然，联合共现表征与类别感知多样性核，在四个数据集上 Recall/NDCG 提升 6–25% 且同时提升多样性。

    Behavior-Dependent Linear Recurrent Units for Efficient Sequential RecommendationCIKMSeq2024

    以行为依赖的实数线性循环单元 BD-LRU + Triton 并行扫描核，同时达成强性能、快训练与低推理成本，Full-Ranking 下 ML-1M HR@10 提升 7.46%。

    Contrastive Learning on Medical Intents for Sequential Prescription RecommendationCIKMSeqSSL2024

    ARCI 用跨就诊 Transformer 抽取多条“时间路径”，并以意图对比学习正则化多头注意力，在 MIMIC-III/AKI 全库排序上命中率较 SOTA 提升 5–7%。

    DivNet: Diversity-Aware Self-Correcting Sequential Recommendation NetworksCIKMSeqMTL2024

    将整页集体推荐改写为带因果掩码的指针式序列选择，用自校正解码建模物品相互激发，并以相似度行列式注入多样性；线上 page CTR +8.7%。

    MARS: Matching Attribute-aware Representations for Text-based Sequential RecommendationCIKMSeqLLM4Rec2024

    用属性级多向量文本编码 + 逐属性 MaxSim 匹配替代单一序列向量，在全库排序下 R@10 最高提升 24.43%，零样本迁移平均提升 13.11%。

    RECE: Reduced Cross-Entropy Loss for Large-Catalogue Sequential RecommendersCIKMSeqCF2024

    用 GPU 友好的 LSH 分桶+MIPS 近似筛选高梯度负类，将全库 cross-entropy 的 logits 张量切片计算，峰值显存最多降 12 倍且质量持平或超越。

    Sequence-level Semantic Representation Fusion for Recommender SystemsCIKMSeqMM2024

    频域互滤波实现文本-ID 序列级语义融合，等价于上下文卷积；全库排序下 ML-1M/OR 提升 14%/38%。

    UniRec: A Dual Enhancement of Uniformity and Frequency in Sequential RecommendationsCIKMSeqCold2024

    用序列时间均匀性与物品频次构建双向增强分支，配合多维时间混合注意力，在 4 个数据集采样排序协议下 NDCG@10 相对最强基线提升 2.2%–8.9%。

    ✨ 生成式推荐与离散语义 ID (3)

    Content-Based Collaborative Generation for Recommender SystemsCIKMGenRecCF2024

    ColaRec 用 LightGCN 层次聚类构造协同 GID，T5 序列到序列直接生成物品标识，并以物品索引任务+对比损失对齐内容与协同空间；四数据集 8:1:1 全库排序 Recall@20 提升 3.5%–6.7%。

    Learnable Item Tokenization for Generative RecommendationCIKMGenRecLLM4Rec2024

    CIKM 2024｜生成式推荐与离散语义ID：LETTER 以 RQ-VAE 层级码、协同对比对齐和码本多样性正则学习物品标识符，并加排序引导生成损失；三数据集 LOO 全库排序 R@10 较 TIGER/LC-Rec 提升 4.7%–10.8%。

    Multi-Behavior Generative RecommendationCIKMGenRecSeq2024

    将多行为序列推荐重构为「先预测行为、再预测物品」的生成式两步解码，配合均衡语义ID与位置路由稀疏MoE，全库排序相对提升31%~70%。

    🧠 大语言模型推荐 (LLM4Rec) (4)

    Breaking the Barrier: Utilizing Large Language Models for Industrial Recommendation Systems through an Inferential Knowledge GraphCIKMLLM4RecGraph2024

    CIKM 2024[LLM推荐] 用 LLM 离线构建互补知识图，结合 U2E2I 召回与 E-E-I 精排校准；在支付宝三场景 AUC 与线上转化显著提升。

    Collaborative Cross-modal Fusion with Large Language Model for RecommendationCIKMLLM4RecCTR2024

    以混合 Prompt 单 token 承载双模态，用 GATE 维度级门控融合 LLM 语义与 CF 协同嵌入，CTR 全量 AUC 相对 MF 提升 56.21%。

    Enhancing Content-based Recommendation via Large Language ModelCIKMLLM4RecCross2024

    CIKM 2024｜LLM4Rec：LoRA 跨域语义插件经 DARE 合并，再用 ID-内容对比对齐做评分预测；Amazon 11 域 8:1:1 划分下 MSE 显著优于 RGCL。

    Large Language Models Enhanced Collaborative FilteringCIKMLLM4RecCTR2024

    离线微调 RecGen-LLaMA 生成 CoT 推理构建 in-context 样例库，在线用轻量 Transformer 解码器蒸馏出“世界知识+推理引导的协同过滤特征”注入任意骨干模型，CTR 上 AUC RelaImpr 最高 7.6%。

    🗣️ 对话推荐与智能体仿真 (2)

    MemoCRS: Memory-enhanced Sequential Conversational Recommender Systems with Large Language ModelsCIKMCRSLLM4Rec2024

    用实体记忆库与通用记忆增强 LLM，建模跨会话偏好连续性；时序切分下 MRR@20 最高提升 38.5%。

    Reformulating Conversational Recommender Systems as Tri-Phase Offline Policy LearningCIKMCRSRL2024

    将 CRS 重构为「用户建模—离线策略—独立可控仿真评估」三阶段解耦范式，Yelp SR@15 达 0.415 且 AT 降至 11.62。

    🧩 多模态推荐与内容理解 (5)

    AlignRec: Aligning and Training in Multimodal RecommendationsCIKMMMSSL2024

    将多模态推荐目标拆解为内容内、内容-类别、用户-物品三重对齐，配合两阶段解耦训练与中间评估协议，全库排序 R@20 相对提升 4.9%–8.0%。

    Do We Really Need to Drop Items with Missing Modalities in Multimodal Recommendation?CIKMMMSSL2024

    用免训练插补替代“丢弃缺失模态物品”，提出 NeighMean/MultiHop/PersPageRank 三种图感知插补，在 Amazon 三域 Recall@20 最高提升 20.8%。

    Enhancing Taobao Display Advertising with Multimodal Representations: Challenges, Approaches and InsightsCIKMMMCold2024

    淘宝展示广告两阶段多模态框架：语义感知对比学习预训练 + SimTier 相似度分桶与 MAKE 多轮解耦集成，离线 GAUC +1.25%，线上 CTR +3.5%、新广告 CTR +6.9%。

    Natural Language-Assisted Multi-modal Medication RecommendationCIKMMMLLM4Rec2024

    将组合用药推荐建模为患者-药物双模态对齐与相似度检索，用 PLM 抽取病历与药物文本知识，Jaccard 平均提升 4.72%。

    Personalized Video Summarization by Multimodal Video UnderstandingCIKMMMLLM4Rec2024

    将长视频文本化后按 genre 偏好做 T5 语义打分选场景，UserPrefSum F1 26.8 较 UniVTG 提升 13.6%，免训练、推理常数时间

    👥 社交与群组推荐 (1)

    RecDiff: Diffusion Model for Social RecommendationCIKMSocialSSL2024

    在隐空间用扩散模型对社交图嵌入做多步加噪-去噪，任务感知训练剔除虚假社交边，Yelp Full-Ranking Recall@20 达 0.0597。

    ❄️ 冷启动与长尾推荐 (1)

    GUME: Graphs and User Modalities Enhancement for Long-Tail Multimodal RecommendationCIKMColdMM2024

    用多模态相似度给用户-物品图补边提升长尾连通性，并构造显式交互/扩展兴趣双用户模态做互信息增强与双层对齐去噪，四域 Amazon 全库排序 Recall@20 最高 +3.82%。

    🌐 跨域与多场景推荐 (2)

    EXIT: An EXplicit Interest Transfer Framework for Cross-Domain RecommendationCIKMCrossCTR2024

    用兴趣组合标签显式监督跨域兴趣迁移概率，配合场景选择器抑制负迁移，美团首页线上 CTCVR +1.23%、GTV +3.65%

    LLM4MSR: An LLM-Enhanced Paradigm for Multi-Scenario RecommendationCIKMCrossLLM4Rec2024

    冻结 LLM 以场景级/用户级 Prompt 零样本推理跨场景知识与个性化偏好，经分层元网络生成元层注入多场景 CTR 骨干，AUC 最高相对提升 40% 且推理仅 52ms。

    🎯 CTR/CVR 预估与特征交叉 (2)

    Retrieval-Oriented Knowledge for Click-Through Rate PredictionCIKMCTR2024

    提出ROK，将样本级检索聚合表征蒸馏为参数化知识库，免在线检索，在Tmall/Taobao/Alipay上AUC最高相对提升34.96%。

    TWIN V2: Scaling Ultra-Long User Behavior Sequence Modeling for Enhanced CTR Prediction at KuaishouCIKMCTRSeq2024

    层次聚类压缩生命周期行为，簇感知目标注意力提升快手 CTR 与推荐多样性。

    ⚖️ 多任务学习与列表级重排 (1)

    Pareto-based Multi-Objective Recommender System with Forgetting CurveCIKMMTLDebias2024

    用 Ebbinghaus 遗忘曲线建模快滑负反馈，并以 Pareto 求解器自适应权衡粗排一致性与 recency，KuaiRec 与微信视频号 A/B 验证，GMV +1.45%。

    🎮 强化学习与动态探索推荐 (2)

    ROLeR: Effective Reward Shaping in Offline Reinforcement Learning for Recommender SystemsCIKMRLDebias2024

    用免训练 kNN 奖励整形与簇内距离不确定性惩罚修正 world model 奖励估计，在 KuaiRec 全观测模拟器上累积奖励较 DORL 提升 62.2%。

    Scalable Dynamic Embedding Size Search for Streaming RecommendationCIKMRLCold2024

    用 SAC 采样 Power-Law 分布参数，在任意内存预算约束下动态增减用户/物品嵌入维度，并以均值池化状态泛化到新用户/物品。

    🛡️ 去偏公平、可信隐私与工业架构 (4)

    Adversarial Text Rewriting for Text-aware Recommender SystemsCIKMDebias2024

    提出 ATR 文本改写攻击，以排名提升损失和两阶段微调攻破文本感知推荐系统，黑盒可行且改写文本较自然。

    An Enhanced Batch Query Architecture in Real-time RecommendationCIKMDebiasCTR2024

    以 NeighborHash（邻域探测+内联偏移）替代传统哈希，配 NVMe 分层 KV 与版本强一致滚动更新，批量点查吞吐近随机访存上界 90%，线上 CTR +2.2%~6.9%。

    Efficient and Robust Regularized Federated RecommendationCIKMDebiasCF2024

    将联邦推荐重构为凸 RERM 问题，提出 RFRec/RFRecF，通信轮次降至 O(log 1/ε)、兼具鲁棒性与差分隐私。

    Watermarking Recommender SystemsCIKMDebiasSeq2024

    提出 AOW 自回归 OOD 水印，为序列推荐植入黑盒可验证版权序列；四数据集 Full-Ranking 达 100% R@1，兼顾效用与抗蒸馏/微调。
