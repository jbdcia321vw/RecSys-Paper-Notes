    🏛️ CIKM 2023 推荐系统论文解读

    59 篇 CIKM 2023 论文解读，覆盖 13 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🔥 高频主题： CTR预估与特征交叉 ×5 · CIKM 2022 ×3 · Contextual Bandit ×2

    🏷️ 标签筛选 仅显示 ≥2 篇论文的标签；默认 AND

    🤝 协同过滤与双塔召回 (3)

    Dimension Independent Mixup for Hard Negative Sample in Collaborative FilteringCIKMCFSSL2023

    从采样区域视角重塑隐式反馈负采样，提出首个 Area-wise 方法 DINS（边界定义+逐维独立 Mixup+多层池化），在 Full-Ranking 协议下 MF backbone 上 Recall@20 最高提升 36.1%。

    Toward a Better Understanding of Loss Functions for Collaborative FilteringCIKMCFSSL2023

    用统一数学框架把 7 种 CF 损失还原为 SSM 的极限特例，并提出边缘感知对齐+加权均匀性损失 MAWU，MF/LightGCN 全库排序下稳定超越 DirectAU 与 SOTA。

    Triplet Losses-based Matrix Factorization for Robust RecommendationsCIKMCFDebias2023

    多重 triplet 损失 + 稀有实体加权矩阵分解，在 LFM-1b 多面公平评测下 MRED 类指标较基线改善 55–89%，总分第 3。

    🕸️ 图神经网络与知识图谱推荐 (2)

    Graph-based Alignment and Uniformity for RecommendationCIKMGraphSSL2023

    以高阶邻域聚合压缩稠密表示并对齐用户/物品，层间池化缓解稀疏，Office R@20 较 DirectAU 提升 16.64%。

    How Expressive are Graph Neural Networks in Recommendation?CIKMGraphCF2023

    提出三层 GNN 表达性度量框架，用链路级「拓扑接近度」替代图同构度量，并给出免学习 GTE 算法与六数据集全库排序验证。

    🔄 自监督对比学习与交互去噪 (2)

    MUSE: Music Recommender System with Shuffle Play Recommendation EnhancementCIKMSSLSeq2023

    针对音乐随机播放会话唯一转移率过高的问题，提出转移频次引导的会话增广与细粒度匹配，在 MSSD 全库排序上稳定超越 12 个基线。

    Robust Basket Recommendation via Noise-tolerated Graph Contrastive LearningCIKMSSLGraph2023

    BNCL 以双行为图/超图与一致性感知对比学习抑制购物篮噪声，全库排序下 R@60 最高 21.10。

    ⏱️ 序列与会话推荐 (9)

    AdaMCT: Adaptive Mixture of CNN-Transformer for Sequential RecommendationCIKMSeq2023

    将局部卷积滤波注入 Transformer，并用层感知、用户自适应的混合系数与 Sigmoid 挤压-激励注意力统一建模长短期兴趣；在三个 Amazon 基准的 1:100 采样排序下 Recall@10 相对最优基线提升 4.1%–8.5%。

    Adaptive Multi-Modalities Fusion in Sequential Recommendation SystemsCIKMSeqMM2023

    用模态图 + 双注意力异步门控，让每个节点自适应选择早期/晚期融合顺序，Amazon 六域 HR@5 平均 +8.6%。

    Attention Calibration for Transformer-based Sequential RecommendationCIKMSeqSSL2023

    揭示 Transformer 序列推荐中注意力权重错配现象，提出空间校准器与对抗校准器直接修正注意力分布，在 4 个数据集 Full-Ranking 下 Recall@20 最高提升 8.65%。

    AutoSeqRec: Autoencoder for Efficient Sequential RecommendationCIKMSeqCF2023

    用单个共享编码器同时重建用户-物品矩阵与转移矩阵行/列，增量推理只更新输入矩阵不更新参数，ML-100K 上 Recall@10 相对提升 35%。

    Diffusion Augmentation for Sequential RecommendationCIKMSeqGenRec2023

    用扩散模型一次性生成高质量伪前序物品序列做数据增强，配合 SU-Net 与两种引导策略，在三个数据集三种骨干上稳定提升 HR/NDCG，尤其缓解长尾用户。

    Query-dominant User Interest Network for Large-Scale Search RankingCIKMSeqCTR2023

    两阶段相关行为检索+参与度融合注意力，Amazon四集全指标平均提升21.19%，线上CTR +7.6%。

    Text Matching Improves Sequential Recommendation by Reducing Popularity BiasesCIKMSeqLLM4Rec2023

    TASTE 用模板将物品与交互历史文本化，经 T5 双塔文本匹配做下一物品推荐，配合会话切分注意力稀疏建模长历史，Full-Ranking 下平均提升约 18%。

    Towards Communication-Efficient Model Updating for On-Device Session-Based RecommendationCIKMSeqDebias2023

    提出组合码压缩物品嵌入，并用栈/队列与MMD自适应压缩端侧更新，在Gowalla/Lastfm上以60倍更小更新逼近云端重训精度。

    TSRec: Enhancing Repeat-Aware Recommendation from a Temporal-Sequential PerspectiveCIKMSeqCold2023

    从时间间隔与序列匹配双视角建模重复消费，三大模块在三个数据集的时间切分采样排序协议下 HR@5 最高相对提升 5.47%。

    🗣️ 对话推荐与智能体仿真 (1)

    Large Language Models as Zero-Shot Conversational RecommendersCIKMCRSLLM4Rec2023

    用极简提示把 GPT-3.5/4、Vicuna、BAIZE 直接当零样本对话推荐器，揭露 CRS 评测中的「重复物品捷径」，并构建 63 万级 Reddit-Movie 真实数据集

    👥 社交与群组推荐 (1)

    Multi-Granularity Attention Model for Group RecommendationCIKMSocialGraph2023

    用子集/群组/超集三级粒度注意力（K-Means 子集聚类 + 组图 GCN + 自注意力融合）挖掘稀疏用户隐偏好，离线 HR/NDCG 全面领先，线上 CTR +1.2%。

    ❄️ 冷启动与长尾推荐 (3)

    An Unified Search and Recommendation Foundation Model for Cold-Start ScenarioCIKMColdCross2023

    用 LLM 域不变文本特征 + 域门控融合 + 域自适应多任务预训练统一建模搜索与推荐，冷启新场景微调后离线 AUC 提升 2.2–4.0 个百分点、线上 PVCTR +17.54%。

    Meta-Learning with Adaptive Weighted Loss for Imbalanced Cold-Start RecommendationCIKMColdSeq2023

    提出 MELO，用序列状态编码器生成用户级自适应损失权重修正 MAML 内循环，在四个评分数据集上显著降低 RMSE/MAE。

    Zero-shot Item-based Recommendation via Multi-task Product Knowledge Graph Pre-TrainingCIKMColdGraph2023

    在商品知识图谱上多任务预训练 SGC 编码器并用 ToA 适配层微调，为无交互物品推断归纳式表征；Xmarket 18 国全库排序 NDCG@20 相对提升 18%–83%。

    🌐 跨域与多场景推荐 (2)

    HAMUR: Hyper Adapter for Multi-Domain RecommendationCIKMCrossCTR2023

    用即插即用领域适配器配合共享超网络实例级动态生成适配器权重，端到端训练，MovieLens/Ali-CCP 上 AUC 全面超越 STAR/APG/MMOE。

    Multi-domain Recommendation with Embedding Disentangling and Domain AlignmentCIKMCrossGraph2023

    EDDA 在模型与嵌入双层解耦域间/域内知识，并用随机游走停靠向量对齐跨域相似节点，采样排序下 AUC 最高 +7.6%、Recall +41.8%。

    📍 时空轨迹与 POI 本地生活推荐 (2)

    STGIN: Spatial-Temporal Graph Interaction Network for Large-scale POI RecommendationCIKMPOIGraph2023

    四视图时空子图+GAT聚合、实时序列门控融合，工业数据 HitRate@200 达 25.87%，线上 CTR +1.1%/RPM +6.3%

    Timestamps as Prompts for Geography-Aware Location RecommendationCIKMPOISeq2023

    以时间戳为解码 Prompt 显式建模待预测时刻，并用移位窗口缓解网格硬边界，Five Dataset Full 采样排序全面领先。

    🎯 CTR/CVR 预估与特征交叉 (13)

    An Incremental Update Framework for Online Recommenders with Data-Driven PriorCIKMCTRDebias2023

    用特征级 CTR 先验 (FP) 与贝叶斯输出级模型先验 (MP) 约束滑窗增量训练，流式切分评估下 Criteo/CIKM2019 AUC 超 ASMG，线上 CTR +1.99%

    Deep Context Interest Network for Click-Through Rate PredictionCIKMCTRSeq2023

    以点击级展示上下文与位置注意力建模用户兴趣，31天工业数据AUC 0.66475，线上CTR/RPM各+1.5%。

    DPAN: Dynamic Preference-based and Attribute-aware Network for Relevant RecommendationsCIKMCTRSeq2023

    属性级双激活+双维压缩重表达分离相似/多样表征，条件动态参数生成融合，AUC 0.6098（RelaImpr +10.69%），线上 CTR +7.62%

    Entire Space Cascade Delayed Feedback Modeling for Effective Conversion Rate PredictionCIKMCTRMTL2023

    将 ECVR 分解为 CVR×(1−RFR)，用全空间 CVRFR 任务加级联延迟辅助塔一并解决 DS/SSB/CDF，线上 ECVR +5.21%。

    FiBiNet++: Reducing Model Size by Low Rank Feature Interaction Layer for CTR PredictionCIKMCTR2023

    用内积双线性+低秩交互层与分组位级SENet+重构FiBiNet，非嵌入参数压缩12–16倍且AUC全面反超。

    iHAS: Instance-wise Hierarchical Architecture Search for Deep Learning Recommendation ModelsCIKMCTRDebias2023

    用带极化正则的伯努利门为每个样本搜出字段级嵌入维度，再聚类并重训簇专属 DLRM；Avazu AUC 0.7815（+0.0038），推理最快。

    Masked Multi-Domain Network: Multi-Type and Multi-Scenario Conversion Rate Prediction with a Single ModelCIKMCTRCross2023

    用参数共享组合、自动掩码与动态加权损失，在单模型单数据集中实现多转化类型×多展示场景 CVR 预测，AUC 与线上 CVR/CPM 均显著提升。

    MEBS: Multi-task End-to-end Bid Shading for Multi-slot Display AdvertisingCIKMCTRMTL2023

    面向多广告位展示广告，用多任务端到端出价折减最大化广告主盈余，离线 Surplus 与线上 GMV/ROI 显著提升。

    MemoNet: Memorizing All Cross Features' Representations Efficiently via Multi-Hash Codebook Network for CTR PredictionCIKMCTR2023

    提出多哈希码本HCNet与MemoNet，以独立记忆存储全部交叉特征，在三大CTR数据集和线上A/B均显著提升。

    MvFS: Multi-view Feature Selection for Recommender SystemCIKMCTR2023

    用多子网+门控的 MoE 式控制器为每条样本自适应选择特征域，并以逐域 tanh 退火替代跨域重加权，在 Avazu/Criteo 四个 CTR 骨干上 AUC 全面超越 AdaFS。

    ⚖️ 多任务学习与列表级重排 (5)

    COPR: Consistency-Oriented Pre-Ranking for Online AdvertisingCIKMMTLCTR2023

    将粗排↔精排的分数对齐松弛为 ECPM 排序对齐，用分块采样与 ΔNDCG 加权 pairwise 损失优化一致性，淘宝线上 +12.3% CTR、+5.6% RPM。

    Deep Task-specific Bottom Representation Network for Multi-Task RecommendationCIKMMTLCTR2023

    CIKM 2023 多任务推荐论文，提出 DTRN 以超网络条件 Transformer 与 SENet 式任务特定底层表征缓解负迁移；在电商与 Tenrec 样本级 AUC/LogLoss 上全面优于 MMoE/PLE/AITM，在线进入率 +2.23%。

    Efficient Multi-Task Learning via Generalist RecommenderCIKMMTLMM2023

    GRec 用多模态 Wide&Deep + 并行 Transformer + 任务-句子级稀疏 MoE 路由，在电信场景离线 AP 与线上 A/B 全面超越 MMoE 与单任务模型。

    Parallel Knowledge Enhancement based Framework for Multi-behavior RecommendationCIKMMTLGraph2023

    以并行流知识投影增强级联多行为 GNN，并用投影解耦多专家消除 MTL 梯度冲突，三数据集 HR@10 最高提升 95.16%。

    Post-hoc Selection of Pareto-Optimal Solutions in Search and RecommendationCIKMMTLDebias2023

    提出 PDU 从帕累托前沿事后挑出唯一可部署解：用样本级 utopia 距离替代聚合点距离，并支持用户级校准。

    🎮 强化学习与动态探索推荐 (2)

    Dynamic Embedding Size Search with Minimum Regret for Streaming Recommender SystemCIKMRLCF2023

    将流式推荐中的动态嵌入维度搜索建模为非平稳 LinUCB 赌博机，用频率+兴趣多样性指标做上下文，取得亚线性遗憾与更低内存/时延。

    Scalable Neural Contextual Bandit for Recommender SystemsCIKMRL2023

    提出 ENR：用 EpiNet 式认知不确定性头与 Thompson 采样替代神经老虎机的高代价矩阵求逆，在 MIND/KuaiRec 在线评测中 CTR +9%、评分 +6%，交互节省 29–56%。

    🛡️ 去偏公平、可信隐私与工业架构 (14)

    BOLT: An Automated Deep Learning Framework for Training and Deploying Large-Scale Search and Recommendation Models on Commodity CPU HardwareCIKMDebiasSeq2023

    以 LSH 动态稀疏层在商用 CPU 上训练十亿级搜索推荐模型，辅以稀疏超参自动调优与稀疏推理，精度持平 GPU 基线而延迟与碳排降一个数量级。

    CDR: Conservative Doubly Robust Learning for Debiased RecommendationCIKMDebiasRL2023

    揭示 DR 去偏中占比>35% 的“有毒插补”，用 MC-Dropout 估计插补均值/方差做保守门控，即插即用，KuaiRand NDCG@5 提升 6.27%。

    Contrastive Counterfactual Learning for Causality-aware Interpretable Recommender SystemsCIKMDebiasSSL2023

    用因果图定位曝光混杂，提出CCL以反事实正采样做对比学习去偏，在Coat/Yahoo! R3无偏测试集全库排序上超越IPS/CVIB。

    Counterfactual Graph Augmentation for Consumer Unfairness Mitigation in Recommender SystemsCIKMDebiasGraph2023

    用 B 维可微二值边选择向量对二部图做反事实增广，以 ApproxNDCG 组间差损失只抬升劣势群体效用，让“解释不公平”直接变成“缓解不公平”。

    Decentralized Graph Neural Network for Privacy-Preserving RecommendationCIKMDebiasGraph2023

    DGREC 用「用户内物品超图兴趣凝聚 + 邻域 1-bit 梯度编码共享」，构建首个去中心化 GNN 推荐框架，满足 (1.5,ε)-RDP 且解码无偏，全库排序 recall@20 较最佳隐私基线提升 7.6%–25.2%。

    EvalRS: a Rounded Evaluation of Recommender SystemsCIKMDebiasCold2023

    提出EvalRS挑战，以LFM音乐数据和RecList切片/行为测试补充MRR/HR，采用留一法、25%用户×4次随机评审与bootstrap校验，推动全方位评测。

    G-Meta: Distributed Meta Learning in GPU Clusters for Large-Scale Recommender SystemsCIKMDebiasCold2023

    面向 MAML 类元学习 DLRM 的 GPU 混合并行训练系统，以 AlltoAll/AllReduce 分工与 Meta-IO 流水线把端到端吞吐提升 22%+、模型交付缩短 4 倍，线上 CVR +6.48%。

    Item-based Variational Auto-encoder for Fair Music RecommendationCIKMDebiasCF2023

    将 VAE-CF 转置为物品视角并按流行度分组训练、加组间重建公平正则, 配合配额式列表拼装与 BPRMF 兜底, 用 MRED 与行为测试换取长尾曝光公平。

    KuaiSAR: A Unified Search And Recommendation DatasetCIKMDebiasCross2023

    首个快手真实搜索-推荐统一行为数据集，含跨服务跳转与搜索入口标签，2.6万用户1966万交互

    RecRec: Algorithmic Recourse for Recommender SystemsCIKMDebias2023

    首次形式化内容提供方视角的推荐补救，用特征空间梯度下降+L1/IHT 稀疏化把物品推进目标人群 top-10，三数据集成功率 80–100%、RBO>99.4%。
