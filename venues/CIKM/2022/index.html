    🏛️ CIKM 2022 推荐系统论文解读

    48 篇 CIKM 2022 论文解读，覆盖 11 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🔥 高频主题： CTR预估与特征交叉 ×3 · 对比学习 ×3 · 去偏公平与可信推荐 ×2 · 曝光偏差 ×2

    🏷️ 标签筛选 仅显示 ≥2 篇论文的标签；默认 AND

    🤝 协同过滤与双塔召回 (5)

    A Gumbel-based Rating Prediction Framework for Imbalanced RecommendationCIKMCFDebias2022

    以 Gumbel 变分编码器把评分频率映射到非正态空间，多尺度卷积融合评论交互特征并加残差个性化，5 数据集上 MAE 最高相对降 57.82%。

    Adapting Triplet Importance of Implicit Feedback for Personalized RecommendationCIKMCFSSL2022

    以双层优化学习 (u,i,j) 三元组重要性权重，结合单/多兴趣状态设计与端到端物品聚类，Recall@20 较最优基线提升 3–21%。

    CROLoss: Towards a Customizable Loss for Retrieval Models in Recommender SystemsCIKMCF2022

    将 Recall@N 重写为可微的成对比较核函数加权形式，用幂律权重 $w_\alpha$ 定制检索规模 N 并派生 Lambda 双核梯度法；Amazon/Taobao 召回指标相对交叉熵提升 5–12%，线上 A/B 收入 +4.75%。

    MIC: Model-agnostic Integrated Cross-channel RecommendersCIKMCFSSL2022

    用跨通道对比学习把 U2I/U2U/I2I 三路召回统一进单模型，作为即插即用插件同时提升召回精度与多样性，并在腾讯新闻线上生效。

    Prototypical Contrastive Learning and Adaptive Interest Selection for Candidate Generation in RecommendationsCIKMCFSSL2022

    用可微掩码按用户活跃度自适应选择兴趣向量数目，并以聚类原型对比学习缓解负采样类冲突，1:100 采样排序下 HR@10 相对提升 5–9%。

    🕸️ 图神经网络与知识图谱推荐 (5)

    Automatic Meta-Path Discovery for Effective Graph-Based RecommendationCIKMGraph2022

    提出RMS强化学习元路径自动选择与HRec注意力聚合推荐器；在Yelp/Douban/TCL的Leave-One-Out、1正+499负采样排序下，HR@3较最佳基线最高提升12.7%。

    HySAGE: A Hybrid Static and Adaptive Graph Embedding Network for Context-Drifting RecommendationsCIKMGraphMM2022

    解耦静态交互图嵌入与漂移上下文自适应嵌入，注意力交互融合，全库未交互排序下 HR@10 最高提升 28.4%

    Improving Knowledge-aware Recommendation with Multi-level Interactive Contrastive LearningCIKMGraphSSL2022

    提出 KGIC：以 GNN 层为视图做图内 CF-KG 与图间局部-非局部两层交互对比，三数据集 AUC 相对提升 0.67%–3.35%。

    SUGER: A Subgraph-based Graph Convolutional Network Method for Bundle RecommendationCIKMGraphCross2022

    以用户-捆绑包为中心抽取异质 k 跳子图，用两级 RGCN 图级编码器打分，并删除中心边消除标签泄漏；Recall@20 在 Youshu/Netease 上相对 BGCN 提升 39%/90%。

    SVD-GCN: A Simplified Graph Convolution Paradigm for RecommendationCIKMGraphCF2022

    用截断 SVD 替代 GCN 邻域聚合，仅取 K 个奇异向量并重归一化，全库排序精度提升且百倍加速。

    🔄 自监督对比学习与交互去噪 (2)

    A Comprehensive Survey on Self-Supervised Learning for RecommendationCIKMSSLCF2022

    系统综述 170+ 篇 SSL4Rec 工作，提出对比/重建/对抗三范式与九场景视图中心分类，汇总评估协议并维护开源库 SSLRec。

    Adaptive Fusion Graph Contrastive Learning for RecommendationCIKMSSLGraph2022

    AFGCL以免数据增强的传播层自适应融合与交互锚点对比目标，提升稀疏推荐精度并降低训练成本。

    ⏱️ 序列与会话推荐 (9)

    Beyond Learning from Next Item: Sequential Recommendation via Personalized Interest SustainabilityCIKMSeqCold2022

    用「训练期末段消费预测」任务刻画个性化兴趣持续性(PIS)，并以内在/外在双路稀疏历史补充方案与原型度量偏好学习联合训练，11 数据集全库采样排序全面超越 10 个基线。

    ContrastVAE: Contrastive Variational AutoEncoder for Sequential RecommendationCIKMSeqSSL2022

    双视角ContrastELBO耦合双分支VAE与潜空间对比增强，缓解后验坍缩，Full-Ranking下R@40最高提升19.34%。

    Disentangling Past-Future Modeling in Sequential Recommendation via Dual NetworksCIKMSeq2022

    提出双网络分离过去/未来建模，并以双向KL迁移互补知识，缓解训练-推理鸿沟；4数据集采样排序上HR@1平均提升12.03%。

    Evolutionary Preference Learning via Graph Nested GRU ODE for Session-based RecommendationCIKMSeqGraph2022

    将会话建模为连续时间动态图，以GNG-ODE与t-Alignment学习偏好连续演化，全库排序下MRR@20最高提升6.05%。

    Explanation Guided Contrastive Learning for Sequential RecommendationCIKMSeqSSL2022

    用解释方法（Saliency/Occlusion）估计序列物品重要性，指导正负视图增强与自监督+监督对比学习；四数据集 Full-Ranking 下 NDCG@5 较 CL4SRec 提升 14%–22%。

    Implicit Session Contexts for Next-Item RecommendationsCIKMSeqGraph2022

    会话-物品图 GraphSAGE 嵌入 + K-means 聚类生成隐式会话上下文，用双 Bi-LSTM 上下文预测器作先验特征，Foursquare MRR 相对最优基线 +36.5%。

    Intra-session Context-aware Feed Recommendation in Live SystemsCIKMSeqMTL2022

    将信息流会话建模为点击/滑动的马尔可夫事件链，以会话内曝光序列编码上下文，多任务联合学习并用 GPT 式贪心序列生成优化总曝光与总点击；线上人均曝光 +1.16%、转化 +1.56%。

    Multi-level Contrastive Learning Framework for Sequential RecommendationCIKMSeqSSL2022

    MCLSR 构建序列/用户-物品/用户-用户/物品-物品四视图，在兴趣层与特征层做跨视图对比学习以补足稀疏监督信号，四数据集 Full-Ranking 下 Recall@20 平均相对提升约 7%。

    Time Lag Aware Sequential RecommendationCIKMSeq2022

    用层级自注意力分离全局稳定/局部波动的用户偏好，并以时间差驱动的维度级门向量融合长短期表征，Amazon Book 上 Hit@20 相对提升 55%。

    🗣️ 对话推荐与智能体仿真 (1)

    Rethinking Conversational Recommendations: Is Decision Tree All You Need?CIKMCRS2022

    用用户-物品交互树/随机森林替代RL，按属性提问并排序候选，SR@10最高提升41.5%

    👥 社交与群组推荐 (1)

    Disentangled Contrastive Learning for Social RecommendationCIKMSocialSSL2022

    将用户表征按协同域/社交域显式解耦，并用跨域对比学习迁移社交知识，Dianping/Ciao 上 NDCG 相对 SGL 提升 5.3%/6.5%。

    ❄️ 冷启动与长尾推荐 (1)

    GIFT: Graph-guIded Feature Transfer for Cold-Start Video Click-Through Rate PredictionCIKMColdGraph2022

    构建物理+多模态语义异构链接，用 metapath 引导的 target attention 把热视频的 ID 表征与统计特征迁移给新视频，淘宝线上 CTR 提升 6.82%。

    🌐 跨域与多场景推荐 (4)

    Adaptive Domain Interest Network for Multi-domain RecommendationCIKMCrossCF2022

    ADI 用共享/领域专属双路网络 + DSBN + SE 域注意力 + 跨域自训练伪标签，在阿里展示广告三场景召回上全场景 Recall 提升，线上 RPM +1.8%。

    Contrastive Cross-Domain Sequential RecommendationCIKMCrossSeq2022

    联合建模序列内/间物品关系，双目标学单域/跨域表征，并以对比 Infomax 互信息约束跨域迁移；修正时间穿越划分后 HR@10 相对 SOTA 提升 14%+

    GReS: Graphical Cross-domain Recommendation for Supply Chain PlatformCIKMCrossGraph2022

    为餐饮供应链平台设计「菜品-类目-食材」三层树形元结构与 Tree2vec(GCN+BERT) 编码，配合异构图 Node2vec 与元素级注意力融合，HR@10 相对最强基线提升 7.35%

    Scenario-Adaptive and Self-Supervised Model for Multi-Scenario Personalized RecommendationCIKMCrossSSL2022

    SASS 用场景自适应门控做细粒度全局→单场景信息迁移，并以场景监督对比预训练挖掘无标签全空间样本，淘宝短视频 AWT +8%。

    🎯 CTR/CVR 预估与特征交叉 (9)

    AMinerGNN: Heterogeneous Graph Neural Network for Paper Click-through Rate Prediction with Fusion QueryCIKMCTRGraph2022

    构建 user-paper-keyword 异构图统一表征，用距离协方差注意力动态融合 userID 与 keyword 双查询，AMiner_KRS 上 AUC 0.899（较 MGDSPR +3.2%），线上 UV-CTR 提升 9.6%。

    Graph Based Long-Term And Short-Term Interest Model for Click-Through Rate PredictionCIKMCTRSeq2022

    用图检索结构替代长行为截断/硬类目过滤，结合多场景 GRU 短期意图与个性化门控融合，离线 AUC 达 0.9830，线上 CTR +4.9%。

    Hierarchically Fusing Long and Short-Term User Interests for Click-Through Rate Prediction in Product SearchCIKMCTRSSL2022

    HIFN 以查询/目标/因果三路编码短期兴趣、注意力聚合长期兴趣、门控自适应融合并用自监督代理对比解耦长短期，Fliggy 线上 CTR +5.13%

    IntTower: the Next Generation of Two-Tower Model for Pre-Ranking SystemCIKMCTRMTL2022

    用 Light-SE 特征选择、FE-Block 早期细粒度交互与对比交互正则，在保持双塔解耦部署的前提下逼近单塔精排效果。

    Multi-Scale User Behavior Network for Entire Space Multi-Task LearningCIKMCTRSeq2022

    分层循环网络 HEROES 用 Hawkes 过程与门控跨层通道，在 observation→click→conversion 全空间多尺度建模用户行为，CVR AUC 最高相对提升 11.2%。

    OptEmbed: Learning Optimal Embedding Table for Click-through Rate PredictionCIKMCTR2022

    用可学习场级阈值剪冗余嵌入 + 均匀采样超网与进化搜索定场级维度，在 Criteo/Avazu/KDD12 上省 39%–97% 参数且 AUC 最高 +0.15%。

    Sampling Is All You Need on Modeling Long-Term User Behaviors for CTR PredictionCIKMCTRSeq2022

    用多轮 SimHash 碰撞概率替代 target attention，直接 gather 同签名行为构造长序列用户兴趣，AUC 媲美全注意力且训练快 5–11×，美团线上升 +2.98% CTR。

    Sparse Attentive Memory Network for Click-through Rate Prediction with Long SequencesCIKMCTRSeq2022

    以目标物品为 Query、千长行为序列为知识库，用目标+记忆双查询稀疏注意力与 O(1) 次迭代记忆更新，实现 O(L) 复杂度长序列 CTR 建模，线上 A/B 提升 CTR 7.30%。

    Visual Encoding and Debiasing for CTR PredictionCIKMCTRMM2022

    用自监督+点击监督两阶段对比学习微调视觉编码器，并在 CTR 塔内加对比去偏网络与门控融合，淘宝十亿级数据 AUC +6.8%、线上 CTR +4~5%。

    ⚖️ 多任务学习与列表级重排 (2)

    Real-time Short Video Recommendation on Mobile DevicesCIKMMTLDebias2022

    端侧轻量排序模型融合实时反馈交叉特征，并以自适应束搜索做上下文感知重排，线上有效播放/点赞/关注分别 +1.28%/+8.22%/+13.6%

    Towards Confidence-aware Calibrated RecommendationCIKMMTLDebias2022

    提出置信度感知校准重排CCL，用用户画像大小加权MILP平衡相关性、校准与多样性，MovieLens上nDCG与覆盖率提升

    🛡️ 去偏公平、可信隐私与工业架构 (9)

    Debiasing Neighbor Aggregation for Graph Neural Network in Recommender SystemsCIKMDebiasGraph2022

    把逆倾向权重下推进 GNN 邻居聚合，用加权随机游走拉普拉斯归一化，推理期免训练重聚合即可在 Alexa 上提升 NDCG@5 14.2%。

    Dually Enhanced Propensity Score Estimation in Sequential RecommendationCIKMDebiasSeq2022

    提出用户/物品双视角时序 IPS 与双 Transformer，理论无偏并显著提升序列推荐。

    Dynamic Causal Collaborative FilteringCIKMDebiasSeq2022

    用含环因果图与马尔可夫吸收态分析刻画推荐回声室，提出后门调整+反事实历史的 ∂CCF，内容多样性变化平均降低 7.2%。

    KuaiRand: An Unbiased Sequential Recommendation Dataset with Randomly Exposed VideosCIKMDebiasSeq2022

    快手无感插入百万级随机曝光视频，构建首个带丰富特征与12类反馈的大规模无偏序列推荐数据集，支撑 IPS 全库评估。

    KuaiRec: A Fully-observed Dataset and Insights for Evaluating Recommender SystemsCIKMDebiasCRS2022

    发布快手全观测数据集KuaiRec，揭示数据密度与曝光偏差会改变CRS离线评测排序，矩阵补全仅部分缓解。

    Personalized Federated Recommendation via Joint Representation Learning, User Clustering, and Model AdaptationCIKMDebiasGraph2022

    提出 PerFedRec，用联邦 GNN 联合学习表征、用户聚类与三级模型自适应，实现个性化联邦推荐并降低通信开销，HR@10 较 FedAvg 平均提升 29.47%

    Quantifying and Mitigating Popularity Bias in Conversational Recommender SystemsCIKMDebiasCRS2022

    系统量化对话推荐中曝光/成功率/对话效用三重流行度偏差，提出 PAL+CSM+DPL 三阶段模型无关去偏框架，在 Yelp/Lastfm 上平均降偏 42.5% 且成功率提升 12.3%。

    Rank List Sensitivity of Recommender Systems to Interaction PerturbationsCIKMDebiasSeq2022

    提出排序列表敏感度 RLS 指标与 CASPER 级联扰动法，量化单条交互扰动致全库排序剧变，并揭示低准确率用户更脆弱

    Towards Principled User-side Recommender SystemsCIKMDebiasGraph2022

    用 k-NN 度量恢复理论证明用户侧推荐可行，并提出满足一致性/可靠性/局部性三公理的 Consul 算法，通信开销降低约 8–19 倍且性能近 Oracle。
