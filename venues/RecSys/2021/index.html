    🏛️ RecSys 2021 推荐系统论文解读

    37 篇 RecSys 2021 论文解读，覆盖 9 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🔥 高频主题： Off-Policy Evaluation ×2 · 离线评测 ×2 · 联邦协同过滤 ×2

    🏷️ 标签筛选 仅显示 ≥2 篇论文的标签；默认 AND

    🤝 协同过滤与双塔召回 (4)

    Automatic Collection Creation and RecommendationRecSysCF2021

    在ALS/双塔DNN嵌入上做UMAP降维+HDBSCAN密度聚类自动生成个性化歌单，线上A/B推荐驱动消费2.94→6.83首/日(2.3x)

    Hierarchical Latent Relation Modeling for Collaborative Metric LearningRecSysCF2021

    用记忆网络注意力分层建模物品-物品与用户-物品潜在翻译向量，改造 CML 三元组损失；Full-Ranking 下 MovieLens/Echonest 排名指标较 AdaCML 提升约 7%/18%。

    Reenvisioning Collaborative Filtering vs Matrix FactorizationRecSysCFDebias2021

    复现 NCF vs MF 精度对比并扩展至长尾、多样性与偏差维度，证实 MF 精度与长尾双赢、NeuMF 覆盖率更高。

    Reverse Maximum Inner Product Search: How to efficiently find users who would like to buy my item?RecSysCF2021

    提出精确反向MIPS算法Simpfer，用范数排序、下界数组与块级过滤实现O(1)剪枝，四数据集至少两个数量级加速。

    🕸️ 图神经网络与知识图谱推荐 (1)

    Sparse Feature Factorization for Recommender Systems with Knowledge GraphsRecSysGraphCF2021

    KGFlex 以熵驱动信息增益为用户-特征对赋权，仅在用户相关 KG 特征上做稀疏因子分解，全库排序下精度可比、多样性与长尾覆盖显著更优。

    ⏱️ 序列与会话推荐 (8)

    A Case Study on Sampling Strategies for Evaluating Neural Sequential Item Recommendation ModelsRecSysSeq2021

    复训4个神经序列推荐模型于5数据集，证明Uniform与Popular采样排序均可能偏离全库排序，η=100无通用安全性，应优先Full-Ranking。

    Denoising User-aware Memory Network for RecommendationRecSysSeqSSL2021

    以显式反馈正交投影净化隐式反馈噪声，并用四路用户级记忆网络建模长期兴趣，AUC 较最优基线提升 1.18/0.97 个点。

    Global-Local Item Embedding for Temporal Set PredictionRecSysSeqCF2021

    GLOIE 用时间衰减集合和的 VAE（Tweedie 输出）刻画全局协同信号，与动态图学到的局部序列嵌入做注意力融合，在三个下一篮基准的全库排序上稳定领先 DNNTSP。

    Large-Scale Modeling of Mobile User Click Behaviors Using Deep LearningRecSysSeqMM2021

    分层 Transformer + 神经指针在真实屏幕候选元素上做 next-click 全候选排序，用户级划分下 Top-1 48.3%、Top-3 71.4%，较最强深度基线提升 25.5%。

    Learning to Represent Human Motives for Goal-directed Web BrowsingRecSysSeqCold2021

    提出 GoWeB，用心理学目标分类体系在双曲空间学习目标表征并估计页面访问目标，统一增强会话推荐、重访预测与目标聚类。

    Next-item Recommendations in Short SessionsRecSysSeqCold2021

    将短会话下一项预测建模为小样本学习，用 SSRN 检索跨会话相似历史并做特征级调制，在 Delicious/Reddit 短会话上 Recall@5 最高提升 17.2%。

    Predicting Music Relistening Behavior Using the ACT-R FrameworkRecSysSeqCF2021

    用 ACT-R 声明记忆五组件建模音乐重听，一周滑窗逐 LE 预测会话剩余曲目，R-prec 0.111，较最强单组件 +6.0%。

    Sequence Adaptation via Reinforcement Learning in Recommender SystemsRecSysSeqRL2021

    用 actor-critic 把“回看序列长度 l”建模为 MDP 动作，按用户个性化裁剪子序列并以 Q 值乘性正则交叉熵，Steam/ML-10M 上 NDCG@10 相对最优基线提升 6.5%/12.1%。

    🗣️ 对话推荐与智能体仿真 (2)

    Fast Multi-Step Critiquing for VAE-based Recommender SystemsRecSysCRSMM2021

    M&Ms-VAE 以多模态条件独立 + 专家混合后验建模交互与关键短语，配套冻结主干的自监督门控重排，三任务同时领先且评论推理最高 25.6× 加速。

    Multi-Step Critiquing User Interface for Recommender SystemsRecSysCRSLLM4Rec2021

    构建四套模型无关的多步批判式酒店推荐 Web 界面，把 T-RECS/CE-VAE 的关键词解释与自然语言理由落到真实交互，并定性暴露解释粒度与关键词模糊等失效模式。

    ❄️ 冷启动与长尾推荐 (1)

    Cold Start Similar Artists Ranking with Gravity-Inspired Graph AutoencodersRecSysColdGraph2021

    把新艺人相似艺人排序建模为有向属性图链接预测，用引力启发图自编码器的质量-距离解码器，全库排序下 NDCG@200 相对提升 21%。

    🎯 CTR/CVR 预估与特征交叉 (1)

    An Analysis Of Entire Space Multi-Task Models For Post-Click Conversion PredictionRecSysCTRMTL2021

    在 Twitter 广告 5B 曝光工业数据上系统消融 ESMM 的三大要素，发现仅需硬参数共享或仅需点击加权即可获得全部增益，且二者不可叠加

    ⚖️ 多任务学习与列表级重排 (2)

    Page-level Optimization of e-Commerce Item RecommendationsRecSysMTLRL2021

    将商品详情页模块的选序建模为两阶段 RNN 序列决策，用模块族嵌入压缩动作空间、束搜索+IPS+Thompson 采样实现线上个性化重排，线上 CTR +2.48%、PTR +7.34%。

    Recommendations and Results Organization in Netflix SearchRecSysMTLDebias2021

    Netflix 搜索把协同过滤推荐注入检索，并把结果组织成带标签的横向分组列表做列表级重排，属无量化指标的工业系统论文。

    🎮 强化学习与动态探索推荐 (2)

    Debiased Off-Policy Evaluation for Recommendation SystemsRecSysRLDebias2021

    将 Doubly Robust 与 Double/Debiased ML 结合，用 Neyman 正交+cross-fitting 实现 √N 一致的去偏离线策略评估，线上广告 relative-RMSE 较 DR 降 13.5%。

    Evaluating the Robustness of Off-Policy EvaluationRecSysRLDebias2021

    提出 IEOE，以性能 CDF/AU-CDF/CVaR 替代单点 MSE，量化 OPE 估计器对超参与评估策略的鲁棒性，在 Open Bandit 与真实电商数据上给出安全选型准则。

    🛡️ 去偏公平、可信隐私与工业架构 (16)

    A Payload Optimization Method for Federated Recommender SystemsRecSysDebiasRL2021

    以贝叶斯 Thompson Sampling 在联邦服务器端挑选物品子集传输，实现 90% 载荷削减下仅 4%–8% 精度损失

    An Audit of Misinformation Filter Bubbles on YouTube: Bubble Bursting and Recent Behavior ChangesRecSysDebiasCRS2021

    50 次 sockpuppet 代理审计发现 YouTube 搜索端无气泡生成、推荐端有，且连看 40 条辟谣视频可令推荐归一化分从 0.01 拉回 -0.27。

    Analyzing Item Popularity Bias of Music Recommender Systems: Are Different Genders Equally Affected?RecSysDebiasCF2021

    用中位数/高阶矩/KL/Kendall τ 七维分布度量替代均值差，在 LFM-2b 上揭示七种 CF 算法对女性用户施加更强流行度偏置。

    Black-Box Attacks on Sequential Recommenders via Data-Free Model ExtractionRecSysDebiasSeq2021

    无训练数据下用自回归合成查询 + 排序蒸馏窃取序列推荐模型，并迁移为画像污染与数据投毒攻击，ML-1M 上 Agr@10 达 0.747。

    Debiased Explainable Pairwise Ranking from Implicit FeedbackRecSysDebiasCF2021

    在 BPR 上引入 item 邻域可解释性加权 EBPR，并量化其额外曝光偏差，用 IPS 邻域倾向构造无偏估计 UEBPR，NDCG/MEP 双赢且自带流行度去偏。

    FINN.no Slates Dataset: A new Sequential Dataset Logging Interactions, allViewed Items and Click Responses/No-Click for Recommender Systems ResearchRecSysDebiasRL2021

    发布FINN.no 30天真实市场slate级序列日志，含曝光列表、点击/no-click与搜索/推荐来源，支撑曝光条件似然与离线策略评估。

    Follow the Guides: Disentangling Human and Algorithmic Curation in Online Music ConsumptionRecSysDebias2021

    以 Deezer 9k 用户全年 51M 播放为样本，将入口三分为自然/算法/编辑并聚类出四类用户，揭示编辑拉向流行、算法拉向长尾的相反效应与「过滤小生境」结论

    Learning an Adaptive Meta Model-Generator for Incrementally Updating Recommender SystemsRecSysDebiasCTR2021

    用 GRU 元生成器把增量模型序列压缩成更好服务下一周期的模型，截断序列+多步并发训练，四数据集 AUC 相对提升约 1%

    NU:BRIEF -- A Privacy-aware Newsletter Personalization Engine for PublishersRecSysDebias2021

    RecSys 2021 Demo 论文：以 k-means 兴趣簇代理匿名用户 + 差分隐私 taste vector 实现出版商通讯个性化，A/B 显示 CTR 与人工策展持平、策展耗时下降 80%。

    Online Evaluation Methods for the Causal Effect of RecommendationsRecSysDebias2021

    首个因果 interleaving 在线评估框架，用 EPI/CBI+IPS 无偏比较推荐因果效应，模拟中比 A/B 测试高效约 30 倍。
