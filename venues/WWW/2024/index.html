    🤝 协同过滤与双塔召回 (2)

    Lower-Left Partial AUC: An Effective and Efficient Optimization Metric for RecommendationWWW (TheWebConf)CF2024

    提出LLPAUC双约束部分AUC与点式minimax损失，全库排序下提升Top-K并抗噪。

    RimiRec: Modeling Refined Multi-interest in Hierarchical Structure for RecommendationWWW (TheWebConf)CFGenRec2024

    用层次 k-means 语义类目 ID + Transformer 生成用户多层兴趣圈，再按子库分区训练多塔向量检索；ML-1M/Lofter 全库 Top-M 召回显著优于 MIND/ComiRec，并已上线 Lofter。

    🕸️ 图神经网络与知识图谱推荐 (7)

    Distributionally Robust Graph-based Recommendation SystemWWW (TheWebConf)GraphDebias2024

    将图聚合重写为平滑正则并嵌入DRO边权，配合GEA扩展稀疏邻域，在8个偏移数据集全库排序NDCG上6/8最优。

    GraphPro: Graph Pre-training and Prompt Learning for RecommendationWWW (TheWebConf)GraphCold2024

    时序提示注入图卷积 + 结构提示图与门控微调，动态快照评测下 Recall@20 领先 2.55%–9.77%，线上 CTR +1.53%。

    Knowledge Enhanced Multi-intent Transformer Network for RecommendationWWW (TheWebConf)GraphSSL2024

    以可学习多意图与图Transformer注入全局信号，再用意图引导知识采样和局部-全局对比去噪；三基准与阿里线上A/B均稳定提升。

    Linear-Time Graph Neural Networks for Scalable RecommendationsWWW (TheWebConf)GraphCF2024

    以 PPNP 不动点方程的单层隐式求解 + 高效方差缩减邻居采样，把 GNN 推荐的训练复杂度降到线性 $O(|E|Dd)$，与 MF 同级而精度不降。

    Modeling Balanced Explicit and Implicit Relations with Contrastive Learning for Knowledge Concept Recommendation in MOOCsWWW (TheWebConf)GraphSSL2024

    CL-KCRec 用基向量关系嵌入 GCN + 多通道软选边 GNN 分离建模 MOOC 异质网的显式/隐式关系，并以原型图对比学习做平衡增强；MOOCCube1819 上 N@5 相对最优基线提升 10.2%。

    Personalized Audiobook Recommendations at Spotify Through Graph Neural NetworksWWW (TheWebConf)GraphCold2024

    提出 2T-HGNN：将用户从图里解耦、仅在有声书-播客共听异质图上跑 HGNN 学物品长程表征，再接双塔做实时召回；A/B 上有声书新起播率 +46.83%、播放率 +25.82%。

    Towards Graph Foundation Models for PersonalizationWWW (TheWebConf)GraphLLM4Rec2024

    提出「静态 HGNN + 动态双塔」的个性化领域专用图基础模型：LLM 文本特征统一节点表示、共交互建图跨内容类型共享，单塔双塔适配多品类；工业音频平台 HR@10 相对提升 16.6%。

    🔄 自监督对比学习与交互去噪 (3)

    Enhancing Interpretability and Effectiveness in Recommendation with Numerical Features via Learning to Contrast the Counterfactual samplesWWW (TheWebConf)SSLCTR2024

    以反事实样本合成+对比排序损失显式建模数值特征与模型输出的单调性，模型无关即插即用，KuaiRand/工业集 AUC 最高 +31.2%，线上 collect_rate +3.93%。

    Is Contrastive Learning Necessary? A Study of Data Augmentation vs Contrastive Learning in Sequential RecommendationWWW (TheWebConf)SSLSeq2024

    系统评测8种序列数据增强与3种对比学习SRS，发现slide-window等直接增强可媲美CL且更省算力。

    RecDCL: Dual Contrastive Learning for RecommendationWWW (TheWebConf)SSLGraph2024

    提出用户-物品双对比框架，融合特征维去冗余与批维输出增广，在四个公开集和支付工业集全库排序 Recall@20 最高提升5.65%。

    ⏱️ 序列与会话推荐 (6)

    End-to-End Graph-Sequential Representation Learning for Accurate RecommendationsWWW (TheWebConf)SeqGraph2024

    MRGSRec 用序列+图双编码器、全链路融合层与跨表征对比损失做端到端多表征学习，Leave-One-Out 全库排序下 NDCG@5 较 SASRec+ 最高提升 8.94%。

    END4Rec: Efficient Noise-Decoupling for Multi-Behavior Sequential RecommendationWWW (TheWebConf)SeqSSL2024

    用 FFT 频域算子+双粒度（硬/软）去噪与噪声解耦对比学习做多行为序列推荐，Leave-One-Out+99 负采样评测，三数据集 HR@10 相对提升 5.8%–8.0%。

    Harnessing Large Language Models for Text-Rich Sequential RecommendationWWW (TheWebConf)SeqLLM4Rec2024

    用冻结大模型对长文本行为序列分块做层次/循环摘要压缩，再以 LoRA-SFT 微调 Llama-2-7b 做 Yes/No 判别；MIND 上 Recall@3 相对 TALLRec 提升 6.8%。

    Intelligent Model Update Strategy for Sequential RecommendationWWW (TheWebConf)Seq2024

    提出 IntellectReq，以误推荐检测与分布映射控制边端参数请求，10%通信逼近100%性能。

    Leave No One Behind: Online Self-Supervised Self-Distillation for Sequential RecommendationWWW (TheWebConf)SeqSSL2024

    用在线原型聚类+头尾对抗+簇感知自蒸馏，把长序列知识蒸馏给短序列用户，四数据集全库排序 HR@5 最高提升 9.3%。

    Recommender Transformers with Behavior PathwaysWWW (TheWebConf)Seq2024

    RETR 用可学习的二值路径路由器稀疏激活行为路径，配合 Gumbel-Softmax 与层级门控，在 7 个数据集 Leave-One-Out + 100 负采样协议下取得 SOTA。

    Collaborative Large Language Model for Recommender SystemsWWW (TheWebConf)LLM4RecGenRec2024

    Generative News RecommendationWWW (TheWebConf)LLM4RecGenRec2024

    GNR 用 LLM 生成主题级双层表征做召回，再融合多篇相关新闻生成个性化叙事；在 MIND 政治子集上 NDCG@5 提升 3.08%，UIFT 使叙事胜率达 74.54%。

    Knowledge-Augmented Large Language Models for Personalized Contextual Query SuggestionWWW (TheWebConf)LLM4RecSeq2024

    用实体中心个人知识库检索增强 GPT-4 提示，在 Bing 日志与人工评测上使上下文查询建议的相关性/有用性较 LLM 基线提升约 17%

    Modeling User Viewing Flow Using Large Language Models for Article RecommendationWWW (TheWebConf)LLM4RecSeq2024

    用 LLM 做用户档案摘要、BERT 编码文章并瞬时注意力读历史，ATA 线上 UVCTR 相对 DCN 提升 2.4%

    NoteLLM: A Retrievable Large Language Model for Note RecommendationWWW (TheWebConf)LLM4RecCF2024

    用 Note Compression Prompt 把笔记压缩为单个 [EMB] 隐状态做 I2I 召回，并以话题标签/类目生成做多任务增强；257K 全库 Full-Ranking 下 Avg Recall 94.66%，线上 CTR +16.20%。

    RecAI: Leveraging Large Language Models for Next-Generation Recommender SystemsWWW (TheWebConf)LLM4RecCRS2024

    开源工具包 RecAI 以五大支柱（Agent/RecLM/知识插件/解释器/评测器）打通 LLM 与推荐系统，含 RecLlama 工具规划超越 GPT-3.5、7B 微调排序超越 GPT-4 等定性结论

    Representation Learning with Large Language Models for RecommendationWWW (TheWebConf)LLM4RecSSL2024

    RLMRec 用互信息最大化把 LLM 语义表征与协同表征对齐，模型无关地增强 6 个 CF 骨干，全库排序下 Recall@20 最高提升 7.6%

    How Reliable is Your Simulator? Analysis on the Limitations of Current LLM-based User Simulators for Conversational RecommendationWWW (TheWebConf)CRSLLM4Rec2024

    系统审计 iEvaLM 用户模拟器的数据泄漏与多轮失效，提出意图条件化的 SimpleUserSim，在 ReDial/OpenDialKG 全库 Recall 上还原真实增益。

    Link Recommendation to Augment Influence Diffusion with Provable GuaranteesWWW (TheWebConf)SocialGraph2024

    用可分解增广影响估计器 + 截断/增量 RR 集采样，为种子集选 k 条社交边，在 IC 模型下保持 (1-1/e-ε) 近似并扩展到 4170 万节点图。

    ❄️ 冷启动与长尾推荐 (3)

    Cold-start Bundle Recommendation via Popularity-based Coalescence and Curriculum HeatingWWW (TheWebConf)ColdGraph2024

    CoHeat 以热度自适应加权融合「用户-捆绑」与「用户-物品」双图视图，并借课程升温对齐两视图，冷启动 bundle 的 nDCG@20 最高提升 193%。

    Large Language Models as Data Augmenters for Cold-Start Item RecommendationWWW (TheWebConf)ColdLLM4Rec2024

    用 LLM 成对比较推理生成冷启动物品的合成偏好信号，经辅助 BPR 损失注入 ID-based 推荐模型；Amazon 全库排序下冷启动物品 R@50 提升近 21 倍且几乎不损 warm-start。

    When Federated Recommendation Meets Cold-Start Problem: Separating Item Attributes and User InteractionsWWW (TheWebConf)ColdDebias2024

    首个联邦冷启动推荐框架 IFedRec：服务器端学习物品属性元网络、客户端保留交互物品嵌入，双向对齐两表征使冷物品仅凭属性即可推理。

    🌐 跨域与多场景推荐 (4)

    M-scan: A Multi-Scenario Causal-driven Adaptive Network for RecommendationWWW (TheWebConf)CrossDebias2024

    以因果图把场景影响拆为 S→M→Y 与 S→Y 两路，用场景感知共注意力显式抽取跨场景同向兴趣、用反事实消偏器剔除场景直推偏置；Aliccp/Cloud Theme 全场景 AUC 提升 2.13%/0.96%。

    Prompt-enhanced Federated Content Representation Learning for Cross-domain RecommendationWWW (TheWebConf)CrossDebias2024

    联邦语义码本与提示微调实现非重叠隐私保护跨域序列推荐，全库排序R@10最高提升10.5%。

    Rethinking Cross-Domain Sequential Recommendation under Open-World AssumptionsWWW (TheWebConf)CrossDebias2024

    提出 AMID：多兴趣组建组传播 + 双稳健估计，处理开放世界部分重叠与选择偏差；1:999 采样排序 NDCG@10 最高 +26.48%。

    UnifiedSSR: A Unified Framework of Sequential Search and RecommendationWWW (TheWebConf)CrossSeq2024

    双分支参数共享 Transformer 联合建模搜索与推荐序列，并用可学习意图会话+双路自监督挖掘动态意图，采样排序下两场景 HR/NDCG 全面领先。

    🎯 CTR/CVR 预估与特征交叉 (8)

    A New Creative Generation Pipeline for Click-Through Rate with Stable Diffusion ModelWWW (TheWebConf)CTRMM2024

    以 SD-Inpainting 只改背景保商品，Prompt 模型注入用户分组、多模态 Reward 模型闭环自循环生成高 CTR 创意，线上 CTR +10.4%。

    Discrete Semantic Tokenization for Deep CTR PredictionWWW (TheWebConf)CTRGenRec2024

    用 RQ-VAE 把用户/物品稠密语义压成 4 个离散 token，配分层混合推理 HMI 打分，在 MIND 上以约 200 倍内存压缩保住 98% AUC 且推理仅 3ms。

    Enhancing Cross-domain Click-Through Rate Prediction via Explicit Feature AugmentationWWW (TheWebConf)CTRCross2024

    用跨监督特征翻译器把目标域隐特征映射到源域并拼回原特征做显式增强，免超域依赖、上下文感知，淘宝线上 CTR +0.11pt、GMV +1.26%

    Macro Graph Neural Networks for Online Billion-Scale Recommender SystemsWWW (TheWebConf)CTRGraph2024

    将十亿级微观用户-物品图按行为模式聚类为百级宏节点图，用宏边求和+温度softmax权重与分离式注意力聚合，CTR任务AUC平均+1.00%，线上PCTR+3.13%且响应时间比SIM快20.97%

    MetaSplit: Meta-Split Network for Limited-Stock Product RecommendationWWW (TheWebConf)CTRCold2024

    按库存切分用户序列并引入元缩放/位移网络与辅助损失，解决 C2C 孤品冷启与注意力偏置，线上 CTR +3.56%。

    PPM: A Pre-trained Plug-in Model for Click-through Rate PredictionWWW (TheWebConf)CTRMM2024

    用多模态特征做 ID-free CTR 预训练，以“缓存+部分参数可训”的插件形式接入 IDRec 联合训练，端到端不提延迟，京东线上 UCTR +1.09%。

    RAT: Retrieval-Augmented Transformer for Click-Through Rate PredictionWWW (TheWebConf)CTRCold2024

    用 BM25 检索 K 个历史样本作为参考上下文，以级联 intra/cross attention 建模样本内与跨样本特征交互，AUC 平均较 xDeepFM 提升 1.13%，长尾用户提升更显著。

    Recall-Augmented Ranking: Enhancing Click-Through Rate Prediction Accuracy with Cross-Stage DataWWW (TheWebConf)CTRMTL2024

    RAR 用 SimHash 从跨阶段召回池选出相似用户集与召回物品集，经 set-to-set 匹配矩阵共交互聚合增强排序表征，即插即用；在 KKBox/MovieLens/CandiCTR-Pub 上 AUC 相对提升最高 4.7%。

    ⚖️ 多任务学习与列表级重排 (3)

    A Data-Centric Multi-Objective Learning Framework for Responsible Recommendation SystemsWWW (TheWebConf)MTLDebias2024
