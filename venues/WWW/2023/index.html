    🏛️ WWW (TheWebConf) 2023 推荐系统论文解读

    65 篇 WWW (TheWebConf) 2023 论文解读，覆盖 13 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🔥 高频主题： WWW 2023 ×56 · WWW ×9 · Actor-Critic ×4 · 对比学习 ×4 · 多行为推荐 ×3 · CTR预估与特征交叉 ×2 · 双层优化 ×2 · 多模态推荐 ×2

    🤝 协同过滤与双塔召回 (6)

    Distillation from Heterogeneous Models for Top-K RecommendationWWW (TheWebConf)CFMTL2023

    用教师训练轨迹构造由易到难的排序知识课程，将异构推荐模型集成蒸馏进轻量学生，R@10 最高提升 24.7%。

    Divide and Conquer: Towards Better Embedding-based Retrieval for Recommender Systems From a Multi-task PerspectiveWWW (TheWebConf)CFMTL2023

    将候选库语义聚类后分簇并行 EBR，仅用同簇难负例训练并配合 Prompt 式多任务适配，KuaiRand Recall 最高提升 42.7%，线上 A/B 全指标正向。

    Fine-tuning Partition-aware Item Similarities for Efficient and Scalable RecommendationWWW (TheWebConf)CF2023

    用谱划分把物品相似度建模限制在子划分内，并以全局谱信息微调；4 数据集上全库排序指标超越 GCN，提速 10×、省 95% 参数。

    Graph-less Collaborative FilteringWWW (TheWebConf)CFSSL2023

    用双层知识蒸馏把 GCN 教师压缩为 MLP 学生，配合梯度自适应对比正则，在 Full-Ranking 协议下兼顾精度与推理效率。

    On the Theories Behind Hard Negative Sampling for RecommendationWWW (TheWebConf)CF2023

    证明BPR难负采样等价优化OPAUC，并给出可控硬度与按K调采样策略。

    Towards Explainable Collaborative Filtering with Taste Clusters LearningWWW (TheWebConf)CF2023

    用稀疏「口味簇」隶属矩阵实现自解释 CF，Forest 集成补偿稀疏化损失，三数据集 Recall@20 相对最优基线提升 8.0%–14.6%。

    🕸️ 图神经网络与知识图谱推荐 (7)

    Code Recommendation for Open Source Software DevelopersWWW (TheWebConf)GraphMM2023

    CODER 用异构图联合建模用户-文件微观贡献与用户-项目宏观行为，并以项目文件树聚合桥接两级信号，全库排序下 NDCG@20 最高提升 32.7%。

    Collaboration-Aware Graph Convolutional Network for Recommender SystemsWWW (TheWebConf)Graph2023

    提出CIR拓扑度量与CAGC协同感知图卷积，按邻居共同交互比例重加权，6数据集Full-Ranking下Recall@20较LightGCN平均约+9.1%，训练总时间最高降96.3%。

    Compressed Interaction Graph based Framework for Multi-behavior RecommendationWWW (TheWebConf)GraphMTL2023

    用矩阵乘法显式构造实例级高阶交互图并以节点注意力压缩图空间，配合分离输入多专家网络解耦多任务梯度，Taobao HR@10 相对提升 20.57%。

    Dual Policy Learning for Aggregation Optimization in Graph Neural Network-based Recommender SystemsWWW (TheWebConf)GraphRL2023

    用双 DQN 为每个用户/物品自适应选择聚合跳数，替代固定 GNN 层数超参，LightGCN/KGAT 上 nDCG 最高 +63.7%。

    Dynamically Expandable Graph Convolution for Streaming RecommendationWWW (TheWebConf)GraphSeq2023

    以模型隔离视角对 GCN 卷积核执行剪枝-精炼-扩张，配合时序注意力初始化，实现免历史回放的流式推荐，Taobao2014 R@20 最高提升 146%。

    Multi-Behavior Recommendation with Cascading Graph Convolution NetworksWWW (TheWebConf)GraphMTL2023

    用级联 LightGCN + 特征变换逐跳传递行为链特征、仅用目标行为监督，Beibei/Tmall 全库排序下 Recall@10 相对最强基线提升 23.2%/44.2%。

    Personalized Graph Signal Processing for Collaborative FilteringWWW (TheWebConf)GraphCF2023

    用个性化图信号+增广相似图+混合频率图滤波构建免训练的非参数 CF，随机划分全库排序下 NDCG 平均超越 SOTA 3.5%。

    🔄 自监督对比学习与交互去噪 (4)

    AutoDenoise: Automatic Data Instance Denoising for RecommendationsWWW (TheWebConf)SSLRL2023

    用 DRL 策略网络逐实例做 select/deselect 去噪，配合搜索-验证两阶段交替训练，产出可迁移的干净子集，DeepFM 等骨干 AUC 稳定提升。

    Automated Self-Supervised Learning for RecommendationWWW (TheWebConf)SSLGraph2023

    AutoCF 用可学习掩码 + 图自注意力掩码自编码器替代手工图增广，在全库排序下相对最优 SSL 基线提升 7.8%–33.7% Recall@20。

    Denoising and Prompt-Tuning for Multi-Behavior RecommendationWWW (TheWebConf)SSLGraph2023

    DPT 以三阶段范式先用重构难度无监督去噪辅助行为，再用重初始化与连续提示轻量微调，在 IJCAI/Tmall 上 HR@10 提升 1.58%–2.62%。

    Reweighting Clicks with Dwell Time in RecommendationWWW (TheWebConf)SSLMTL2023

    用停留时间定义有效阅读并以归一化 Sigmoid 重加权点击信号，工业级双塔多任务框架在微信看一看离线 AUC+5.62%、线上 CTR+2.58%。

    ⏱️ 序列与会话推荐 (9)

    A Counterfactual Collaborative Session-based Recommender SystemWWW (TheWebConf)SeqDebias2023

    将会话外因素建模为混杂因子，以自监督伪标签预训练+反事实协同推理消除伪相关，三数据集 R@20 最高提升 21.8%

    A Self-Correcting Sequential RecommenderWWW (TheWebConf)SeqSSL2023

    STEAM 用 item-wise 校正器（keep/delete/insert）+ 两个自监督纠错任务先修序列再推荐，三个数据集 5-core/LOO/99 负采样下 HR@5 最高 +5.9%。

    AutoMLP: Automated MLP for Sequential RecommendationsWWW (TheWebConf)Seq2023

    用双 SRSMLP 分支解耦长/短期兴趣，并以 DARTS 可微搜索短期窗口长度，线性复杂度下 Beauty 的 MRR@10 相对提升 8.5%。

    Debiased Contrastive Learning for Sequential RecommendationWWW (TheWebConf)SeqSSLDebias2023

    提出 DCRec，用三通道从众权重网络解耦用户真实兴趣与流行度从众，并以加权 InfoNCE 实现去偏对比学习，四数据集 LOO 全库排序 HR@1 最高提升 10.29%。

    Dual-interest Factorization-heads Attention for Sequential RecommendationWWW (TheWebConf)SeqSSL2023

    用头对分解注意力与反馈标签掩码建模跳/不跳混合序列，双兴趣解耦塔加 BPR 成对对比，Micro-video GAUC 提升 2.19%。

    Latent User Intent Modeling for Sequential RecommendersWWW (TheWebConf)SeqRL2023

    以条件 VAE 将用户意图建模为潜变量并注入 REINFORCE 序列召回器，三周线上 A/B 使整体满意度 +0.07%、消费多样性 +0.10%。

    Learning Vector-Quantized Item Representation for Transferable Sequential RecommendersWWW (TheWebConf)SeqCross2023

    用 OPQ 将物品文本映射为离散码并查表得表征，配合半合成/混合域难负样本对比预训练与 Gumbel-Sinkhorn 置换对齐微调，跨域跨平台全库排序显著超越 UniSRec。

    Modeling Temporal Positive and Negative Excitation for Sequential RecommendationWWW (TheWebConf)SeqGraph2023

    SDIL 用可学习正/负时间衰减核刻画历史交互的时变激励，并以属性级静态兴趣门控融合，采样排序下 Cellphones MRR 相对提升 10.45%。

    Mutual Wasserstein Discrepancy Minimization for Sequential RecommendationWWW (TheWebConf)SeqSSL2023

    用 2-Wasserstein 距离替代 KL 散度重建对比互信息估计，四数据集全指标相对提升 2.24%–20.10%。

    🗣️ 对话推荐与智能体仿真 (1)

    Enhancing User Personalization in Conversational RecommendersWWW (TheWebConf)CRSCF2023

    提出 MGMCR 多正确答案设定与 UpsRec 框架：NDCG 增益贪心属性问询 + 注意力用户表征精炼器，四数据集 NDCG@10 较 UNICORN 提升 23.6%–58.6% 且轮次减半。

    🧩 多模态推荐与内容理解 (2)

    Bootstrap Latent Representations for Multi-modal RecommendationWWW (TheWebConf)MMSSL2023

    BM3 用隐层 dropout 自举对比视图、免负采样免辅助图，重构交互图并对齐模态特征，全库排序下 R@10 提升 3.7–20.4% 且训练快 2–9 倍。

    Multi-Modal Self-Supervised Learning for RecommendationWWW (TheWebConf)MMSSL2023

    用 Gumbel+WGAN-GP 对抗生成模态感知交互图，再以跨模态对比学习对齐模态偏好，All-Rank 全库排序下 Recall@20 最高提升 16.04%。

    👥 社交与群组推荐 (2)

    ConsRec: Learning Consensus Behind Interactions for Group RecommendationWWW (TheWebConf)SocialGraph2023

    用成员超图、物品二部图与群组加权图三视图建模群组共识，门控自适应融合，采样排序下 Mafengwo HR@5 相对最优基线提升 2.7%。

    Robust Preference-Guided Denoising for Graph based Social RecommendationWWW (TheWebConf)SocialGraph2023

    用交互偏好引导社交图去噪，结合Transformer关系置信度、课程学习与自适应裁剪，在Ciao/Yelp/Douban上稳定提升Diffnet++/MHCN。

    ❄️ 冷启动与长尾推荐 (7)

    Bootstrapping Contrastive Learning Enhanced Music Cold-Start MatchingWWW (TheWebConf)ColdSSL2023

    用动态自举的特征相关性矩阵驱动特征级对比增广，学习鲁棒歌曲表征，并结合聚类人群定向完成冷启歌曲快速加热，全库排序 Recall@50 提升 4.74%，线上有效播放 +38.47%。

    Clustered Embedding Learning for Recommender SystemsWWW (TheWebConf)ColdCTR2023

    提出自上而下分簇嵌入学习 CEL，以梯度主成分分裂簇并动态重分配，在压缩嵌入表的同时显著提升冷物品与线上 AUC。

    ColdNAS: Search to Modulate for User Cold-Start RecommendationWWW (TheWebConf)Cold2023

    把冷启动用户的 FiLM 调制函数与调制位置建模为 NAS 问题，经可证等价的空间变换将 $6^{CL}$搜索空间压缩到$2^{4L}$，一次性可微搜索后在三个基准上稳定超越 MAML 系与超网络系基线。

    Contrastive Collaborative Filtering for Cold-Start Item RecommendationWWW (TheWebConf)ColdSSL2023

    用内容 CF 与共现 CF 双模块的对比学习把共现协同信号隐式"背"进内容编码器，矫正冷启动物品的模糊协同嵌入，全库用户排序下 HR@5 提升 6.1%/29.8%

    Dual Intent Enhanced Graph Neural Network for Session-based New Item RecommendationWWW (TheWebConf)ColdSeq2023

    提出 GSNIR 新设定与 NirGNN：用注意力+β分布双意图模拟用户决策，并以零样本属性推理把新物品映射进 GNN 空间，Amazon G&GF 上 P@20 相对提升 19.33%。

    Few-shot News Recommendation via Cross-lingual TransferWWW (TheWebConf)ColdCross2023

    无重叠用户/新闻的跨语言少样本新闻推荐：跨域新闻检索增广 + 文档级随机掩码 + 新闻对齐 MSE 消除域偏移，MIND→Adressa 4-shot AUC 相对提升 7.69%。

    Semi-supervised Adversarial Learning for Complementary Item RecommendationWWW (TheWebConf)ColdMM2023

    为冷启动商品维护类别专属潜空间并用 CycleGAN 式半监督对抗学习训练跨类别翻译器，类别感知场景 Clothing NDCG 提升 33%。

    🌐 跨域与多场景推荐 (2)

    Continual Transfer Learning for Cross-Domain Click-Through Rate Prediction at TaobaoWWW (TheWebConf)CrossCTR2023

    提出 CTL 新任务与双塔 CTNet，冻结演进中的源域塔、持续训练目标塔并用 GLU 适配器做逐层注入，仅用增量数据即在淘宝 A→B/A→C 提升 GAUC 1.0%/3.6%，线上 CTR +2.5%/+12.3%。

    Cross-domain recommendation via user interest alignmentWWW (TheWebConf)CrossGraph2023

    WWW 2023｜跨域多场景推荐：构建统一跨域异构图并重定义消息传递，再用对比聚类与梯度对齐约束重叠用户兴趣一致；双域留一法 1:99 采样排序下最高相对提升 10.23%。

    🎯 CTR/CVR 预估与特征交叉 (5)

    A Deep Behavior Path Matching Network for Click-Through Rate PredictionWWW (TheWebConf)CTRSeq2023

    提出“行为路径”并做路径级+点击级两级匹配，配合对比增广与自激活去噪，美团线上 CTR +1.6%、广告收入 +1.8%。

    Confidence Ranking for CTR PredictionWWW (TheWebConf)CTRDebias2023

    用“超越线上部署模型”的点式/关系式排序代理损失替代交叉熵与蒸馏，JD 广告精排 A/B 平均 +1.75% CTR。

    Deep Intention-Aware Network for Click-Through Rate PredictionWWW (TheWebConf)CTRMTL2023

    将小程序触发诱导推荐 CTR 分解为「进入意图 × 双条件 CTR」，用后验标注监督意图网络，淘宝聚划算 AUC 0.812、线上 CTR +4.74%

    NASRec: Weight Sharing Neural Architecture Search for Recommender SystemsWWW (TheWebConf)CTR2023

    提出权重共享 NAS 超网与单算子任意连接采样，自动搜索 CTR 特征交叉架构，在 Criteo/Avazu/KDD 取得领先。

    Optimizing Feature Set for Click-Through Rate PredictionWWW (TheWebConf)CTR2023

    OptFS 以特征级门控 + 交互分解把特征集搜索空间从 C(m,2) 降到 m，Criteo 仅留 4.2% 特征仍提升 AUC。

    ⚖️ 多任务学习与列表级重排 (3)

    CAViaR: Context Aware Video RecommendationsWWW (TheWebConf)MTLCTR2023

    用上下文特征让点式模型感知前序视频相似度，贪心式序列重排去冗余；NE 相对降低 0.85%–1.4%，线上互动 +1.7%、DAU +1.5%

    Cooperative Retriever and Ranker in Deep RecommendersWWW (TheWebConf)MTLCF2023

    CoRR 联合训练召回与精排：用自适应采样器从召回分布抽硬负例训精排，用渐近无偏 KL 估计做排序序一致性蒸馏回灌召回，四个大规模数据集 NDCG@10 提升 5–18%。

    Multi-Task Recommendations with Reinforcement LearningWWW (TheWebConf)MTLRL2023

    将会话级交互建模为 MDP，用多 Critic 网络输出 Q 值动态调节各任务 BCE 权重，AUC 相对 SOTA 提升约 0.3–0.6%。

    🎮 强化学习与动态探索推荐 (6)

    Exploration and Regularization of the Latent Action Space in RecommendationWWW (TheWebConf)RLSeq2023

    HAC将列表推荐分解为潜在超动作与效应动作，共享critic并以逆池化对齐和BCE监督稳定RL，在三个模拟在线环境取得约1%–6%的长期收益提升。

    Learning with Exposure Constraints in Recommendation SystemsWWW (TheWebConf)RLDebias2023

    将提供者最低曝光约束建模为分阶段上下文老虎机，提出EES/DP*/LCB*，达到˜O(T^{2/3}) regret并给出Ω(T^{2/3})下界。
